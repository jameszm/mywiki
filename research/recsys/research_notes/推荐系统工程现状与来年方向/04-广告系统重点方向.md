## 1. Meta 广告系统演进：Andromeda / GEM / Lattice / Adaptive Ranking Model / Advantage+，公开架构、算力与收益

### Takeaway
Meta 在 2025H2–2026 已形成"GEM（万亿级稀疏参数的离线基础模型，仅做知识迁移不直接服务）→ Lattice（统一多目标/多 surface 的运行时排序）→ Adaptive Ranking Model（~1T 参数、按请求价值路由算力的在线排序）→ Andromeda（召回+早期排序合并、跨 Nvidia/AMD/MTIA）"的四层栈，并以季度为单位在财报电话会上披露 1%–16% 的转化/点击增量；2026 年的新动向是把生成式模型（Meta Generative Recommender）推进到广告召回、把 GEM 训练集群再扩一档（2026 capex 指引 1150–1350 亿美元），以及把 Advantage+ 做成默认流程（年化 run-rate 超 750 亿美元）。

- `[摘要]` 二手解读称 GEM 架构为"可堆叠的 factorization machines + 跨层 attention"，并引用 Meta 的说法"把数据和算力转成效果的效率约为前代排序模型的 4 倍"。— [ByteByteGo 解读](https://blog.bytebytego.com/p/how-meta-built-a-new-ai-powered-ads)、[Dataslayer 整理](https://www.dataslayer.ai/blog/meta-ads-updates-november-2025-gem-ai-model-boosts-conversions-5) ★（原文未核实）
- `[上线+公开收益]` 2026-08-03/04 Meta 发布 GEM 训练效率博客：GEM"现在在数千块最新一代 GPU 上以 LLM 规模训练"，12 个月内训练 FLOPs 扩大 4 倍的同时，端到端 MFU 翻倍至 20–25%；关键手段：Jagged Flash Attention v4（消除变长序列 padding 最多 50% 的算力浪费，局部 MFU +18.5%、QPS +12%）、GDPA（前向 2x/反向 1.6x，生产环境相对 FA4 最高 3.5x）、BlockAttention（长序列 O(L²)→O(L)）、MXFP8 训练（attention/MLP；配合随机 Hadamard、随机舍入、选择性梯度跳过）、5D 并行（dense 用 2D FSDP + Expert Parallel，节点内 2 路、节点间 16 路；"万亿级"稀疏参数用全分片 2D 模型并行）、NCCLX 的 SM-free 通信（all-gather 占用 SM 从 24 降到 1，全规模端到端 QPS +5%）、自动激活检查点、Base Batch Shuffling（负载均衡 +4%）。模型是"万亿级稀疏 embedding 参数 + 数十亿 dense 参数"的混合架构。展望："下一个 2x 预计以类似方式到来，并随着我们用 agent 自动化部分优化循环而迭代更快"。— 官方博客 [Meta Engineering, 2026-08-03](https://engineering.fb.com/2026/08/03/ml-applications/training-gem-at-llm-scale-meta-ads-recommendation-foundation-model/) `[镜像]` ★★★

**（b）序列建模与 scaling law**
- `[上线+公开收益]` 2026-08-05 博客《From User Sequences to Scaling Laws: A Multi-Stage Architecture for Meta's Ads Ranking》：两段式架构——离线用户建模（异步处理数千长度的用户历史，深层 transformer，结果以 embedding 缓存）+ 在线排序模型（在严格延迟预算内融合缓存的用户表示与候选广告信号）；Dense Tokenization 把稀疏特征与序列行为并入统一词表；target-aware 多头注意力逐层压缩长序列。公开收益：Instagram 转化 +6%、Facebook 转化 +3%、Facebook 点击 +3.5%；观察到"LLM 式 scaling law"（normalized entropy 随 FLOPs 对数线性下降，"没有饱和迹象"）；四个 scaling 杠杆：深/宽/序列长度需均衡、在线排序每单位算力收益陡峭而离线模型可无延迟约束地缓慢扩展、多样化行为类型优于同质序列、基础模型语义特征改善冷启动。对应论文 LLaTTE（arXiv 2601.20083）。— 官方博客 [Meta Engineering, 2026-08-05](https://engineering.fb.com/2026/08/05/ml-applications/from-user-sequences-to-scaling-laws-a-multi-stage-architecture-for-metas-ads-ranking/) `[镜像]` ★★★

**（c）Adaptive Ranking Model（在线侧 LLM 规模模型）**
- `[上线+公开收益]` 2026-03-31 博客：提出"推理三难"（模型复杂度/算力显存 vs 低延迟/低成本），用"请求导向优化"按用户上下文与意图把请求路由到不同复杂度的模型，使"扩展成本从线性变为次线性"；单 token 算力达到"顶级 LLM 的 O(10 GFLOPs)"而延迟仍为 O(100 ms)；多种硬件上 MFU 提升到 35%；微基准引导的选择性 FP8 后训练量化；通过 unified embeddings（多特征共享一张表）达到 O(1T) 参数、跨卡分片、模型加载 <10 分钟（多流下载+远程缓存）；架构演进 Wukong Turbo（No-Bias、small parameter delegation）。收益：2025 Q4 Instagram 上线后广告转化 +3%，目标用户 CTR +5%。— 官方博客 [Meta Engineering, 2026-03-31](https://engineering.fb.com/2026/03/31/ml-applications/meta-adaptive-ranking-model-bending-the-inference-scaling-curve-to-serve-llm-scale-models-for-ads/) `[镜像]` ★★★
- `[二手]` Meta 广告基础设施 VP Matt Steiner 2026-04 访谈：GEM"太大无法直接服务"，先前靠蒸馏到很小的模型；现在用的 Adaptive Ranking Model 是"蒸馏程度低得多的 GEM 变体"，推理时模型"约 1 万亿参数"，在"亚秒级延迟"下评估，并"按用户交互历史长度动态分配算力"；Andromeda 用与 NVIDIA 共同设计的定制硬件 SKU（memory-bound）；Lattice 把多目标模型合并成单模型的三个理由是去重用户兴趣存储、子网只算一次、数据多样性提升预测；硬件为异构（GPU、GraceHopper、MTIA）。— 访谈逐字稿镜像 [Chipstrat / "semi doped" 2026-04-20](https://github.com/yohan4477/semi-report/blob/HEAD/content/semi_doped/raw/2026-04-20-meta-steiner.md) ★★

### Inferences
- Meta 的真正"护城河"不是单个模型，而是训练侧（MFU 20–37%、MXFP8、5D 并行）与推理侧（请求级算力路由、FP8 PTQ、统一 embedding）两套效率工程，使"万亿参数在线排序 + 亚秒延迟"成为可能；财报上每季 1%–6% 的转化增量是多个独立发布叠加，而 Q2 2026 的 +15.7% 转化应理解为多项改进的累计口径（二手整理，未见原文定义）。
- 2026 年 Meta 的叙事从"更大的判别式模型"转向"生成式召回 + LLM 内容理解 + 推荐数据预训练基础模型"，与中国平台（快手 GR4AD、腾讯 GPR）的路线正在收敛。
- Advantage+ run-rate 从 600 亿（2025Q3）到 750 亿美元（2026Q2）说明平台侧自动化已是主流，但 Opportunity Score、多媒体广告等"把控制权换成可解释分数"的产品正是在回应广告主对黑箱的担忧。

## 2. Google 广告：LLM/Gemini 在相关性、匹配、Performance Max、Demand Gen 中的应用

### Takeaway

## 4. 自动出价与自动投放：生成式/扩散/LLM auto-bidding，全自动投放产品，广告主控制与平台优化的矛盾

### Takeaway
自动出价的学术主线已从 RL 走向"生成式轨迹规划（扩散/flow-matching/Decision Transformer）+ 离线评估器/RL 微调 + LLM 规划器"，但 2026 年真正有线上证据的仍是较轻量的生成式策略（快手 BidFlow +0.68% 目标成本、AHBid +13.57% 回报）而非 32B 规划器；产品侧全自动投放已成默认（Meta Advantage+ 750 亿美元 run-rate、Google AI Max 50 万广告主并强制迁移、快手 UAX 非电商渗透近 80%），平台通过"分数/诊断/可配置护栏"而非开放参数来回应广告主对失控的抵触。

- 公开的创意-排序联合优化收益（+0.5%～+3%）小于模型规模化收益，但其价值在于"素材不再是瓶颈"后，创意疲劳与探索成本成为新约束；目前没有平台公开量化"无限创意"对竞价密度或疲劳度的影响。

## 8. 广告与自然内容混排、ad load 控制、整页优化；广告排序大模型化的工程挑战（延迟预算、校准、竞价一致性）

### Takeaway
混排/ad load 的公开落地集中在"统一价值/统一 token 空间"（腾讯 GPR 把广告与自然内容映射到共享 SID；Meta ROCS 统一广告/自然流量 serving；AdKDD 2025 "common currency" 实验广告收入 +35%）与"会话级动态广告负载"（Meta KDD'25 离线鲁棒 RL，两位数权衡效率提升；Meta 2025 年"广告负载再分配"；腾讯视频号 ad load 仍低于同行）。生成式广告排序的工程挑战已有具体答案：GR4AD（LazyAR + 动态 beam + 列表级价值 RL）、OneRanker（生成-排序一致性损失）、Meta Adaptive Ranking（请求级路由 + 选择性 FP8 + O(100ms)），但校准与竞价一致性仍是各家自述的核心难点。

### Cited Findings
- `[论文/已部署]` Meta Session-Level Dynamic Ad Load（KDD'25）：会话内实时个性化广告密度/类型，离线鲁棒 RL，多生产系统部署，参与度-广告权衡效率两位数提升。— [arXiv 2501.05591](https://arxiv.org/abs/2501.05591) ★★★
- `[财报]` Meta 2025Q4："更有效的广告负载再分配"是 2025 年广告表现的投入之一；腾讯 4Q25："视频号广告加载率仍低于同行"。— 见第 1、3 节 ★★★
- `[论文]` More Ads, Happier Shoppers: Unified-Valuation Ad Allocation at Scale（AdKDD 2025）："common currency"统一估值合并赞助与自然结果；6 周、数百万关键词搜索的线上实验：广告覆盖扩大、广告收入 +35%、转化率提升（作者单位未核实）。— [Springer 章节](https://link.springer.com/chapter/10.1007/978-3-032-16358-5_7) ★★
- `[论文/理论]` Merging Mechanisms for Ads and Organic Items in E-commerce Platforms（arXiv 2511.22925，2025-11）：同时满足激励相容、个体理性、多 slot、不可分候选、避免重复曝光的合并机制（generalized fix / change mechanism），给出近似比保证。— [arXiv 2511.22925](https://arxiv.org/abs/2511.22925) ★★
- `[论文]` Adaptive Ad Load Design for Sponsored Search Markets: Evidence, Theory, and Deployment（arXiv 2607.14418，2026-07，华盛顿大学）：在收入与转化约束下动态选择广告数量。— [arXiv 2607.14418](https://arxiv.org/abs/2607.14418) ★★
- `[论文/已部署]` 统一空间：腾讯 GPR（广告与自然内容共享多级 SID）；Meta ROCS（单次 request encoding + 候选侧 late interaction 统一广告/自然召回排序 serving）；Pinterest PinDCO 的像素感知整页调整；背景 JD 虚拟出价混排（2021）。— [arXiv 2511.10138](https://arxiv.org/abs/2511.10138)、[daiwk 目录](https://github.com/daiwk/auto-research/blob/HEAD/docs/reproductions/catalog/by-company.md)、[arXiv 2105.13556](https://arxiv.org/abs/2105.13556) ★★
- `[论文/已部署]` 生成式广告排序的工程设计：GR4AD——LazyAR 放松层间依赖以降低多候选短序列生成成本、dynamic beam serving 按负载调 beam、RSPO 列表级价值 RL 支持持续在线更新、"高吞吐实时 serving"；OneRanker——Fake Item Tokens 隐式目标感知 + 排序解码器显式价值对齐 + KV 直通 + 分布一致性损失解决"生成与排序脱节/单阶段融合的优化张力"；GPR——HHD 双解码器"平衡训练效率与推理灵活性"。— [arXiv 2602.22732](https://arxiv.org/abs/2602.22732)、[arXiv 2603.02999](https://arxiv.org/abs/2603.02999)、[arXiv 2511.10138](https://arxiv.org/abs/2511.10138) ★★★

### Inferences
- 混排正在从"机制设计层"（虚拟出价、合并机制）下沉到"表示层"（共享 SID/统一 serving），这让 ad load 决策可以由同一个模型在会话级做出（Meta 会话级 RL、腾讯 GPR）；但只有 Meta 公开了会话级 ad load 的落地证据。
- 生成式广告排序的三大工程挑战各有公开解法：延迟（LazyAR/动态 beam/请求路由/FP8）、价值对齐（VSL/RSPO/Value-Aware FT/HEPO）、生成-排序一致性（OneRanker DC loss、BAR）；但"生成 logit 的校准是否足以直接定价"尚无公开量化，各家仍保留排序/价值头。

## 9. 未来 12 个月（2026-10 → 2027-10）的判断：最可能的重点投入方向与工程瓶颈

### Takeaway
基于各平台已公开的路线图与 2026 年的发布节奏，未来一年最可能的投入是：(1) 广告基础模型继续按 scaling law 扩算力（Meta 明示 GEM 上更大集群、capex 1150–1350 亿美元；腾讯 AI 投入翻倍）并把生成式模型从召回推进到排序/整页；(2) 全自动投放成为唯一入口（Google 2027-02 强制 DSA→AI Max、Meta 年底"全自动广告"、TikTok Symphony Agent + MCP、快手/字节 UAX/UBMax 渗透率逼近饱和），平台靠可解释分数与护栏换取广告主信任；(3) 出价与排序一致性、延迟反馈多 horizon 标签、增量/建模标签取代归因标签；(4) 瓶颈集中在推理成本（万亿参数亚秒服务、MFU 20–37%）、生成式排序的校准/定价、以及隐私后 Web 信号质量。

### Cited Findings（支撑判断的已公开路线信号）
- Meta：2026 "有意义地把 GEM 训练扩到更大集群"（2025Q4）；"下一个 2x 训练效率将通过 agent 自动化优化循环"（2026-08）；"用推荐数据预训练大型基础模型、观察到健康 scaling law"、生成式模型已进广告召回、"到 2027 年仍有改进空间"（2026Q2）；adaptive ranking 扩展站外转化（2026Q1）；WSJ 报道的 2026 年底全自动广告；2026 capex 1150–1350 亿美元；Business AI 向"按结果付费的拍卖式定价"演进（Zuckerberg，2026Q2）。— 第 1 节来源 ★★★/★★
- Google：DSA→AI Max 强制迁移 2027-02；AI Mode 内 Gemini 广告形态持续测试与部署（2026Q2）；Ask Advisor / Business Agent / Universal Cart 的代理化与 agentic commerce；Meridian + 长期转化度量；Smart Bidding Exploration 全球推广。— 第 2 节来源 ★★
- TikTok：Symphony Agent 全球推广、Smart+ One Buying Experience、TikTok Ads MCP / Agentic Hub（2026-06-30）；Seedance 2.0 素材全面开放。— 第 3 节来源 ★★
- 中国平台：腾讯 2026 年 AI 投入"翻倍以上"、视频号 ad load 低于同行（提升空间）；快手 GR4AD 显示"模型与推理时 scaling 均有持续收益"；百度 2026 竞赛聚焦生成式广告排序推理优化；阿里妈妈 AIGB-R1/Pearl 待线上验证；PlatformBid 把平台收入纳入出价目标。— 第 3、4 节来源 ★★★/★★
- 隐私：Chrome 第三方 cookie 无退役时间线、Sandbox 广告 API 2026-07 移除；AAK 持续迭代、SKAN 无退役日期；Google Customer Match 2026-08 自动启用。— 第 6 节来源 ★★

### Inferences
- 排序模型大模型化的下一步不是更大的判别式模型，而是"离线超大基础模型 + 在线按请求价值分配算力"的两段式（Meta）或"生成式一模型 + 价值对齐 RL + 解码成本控制"（快手/腾讯）；两者都要求训练侧 MFU 与推理侧量化/路由同步推进，预计 2027 年前各家会公开更多 kernel/并行/量化细节而非模型结构。
- 自动出价会进一步与排序合并（出价感知召回、价值感知生成），LLM 规划器更可能先用于"策略/预算层"（周期级、campaign 级）而非毫秒级出价；真正的线上证据需要等 2027 年的 KDD/WWW 工业论文。
- 创意无限供给 + 代理式投放将把"创意级召回与预筛、疲劳与探索控制、整页价值"变成排序系统的常规模块；独立实测对 AI Max 的质疑说明"转化信号质量与校准"将是自动化能否继续扩张的决定因素。
- 对 TikTok 工程师的可比参照：快手 GR4AD/TWICE/PlatformBid、腾讯 GPR/OneRanker、Meta Adaptive Ranking/多段序列架构、Pinterest PinDCO/UniPinRec 是 2025H2–2026 公开细节最完整的五组系统。

### Gaps
- 以上判断基于公开路线图与发布节奏，没有任何平台公开 2027 年的量化目标（如算力分配、延迟预算、收益目标）。
- 本笔记因出网限制未能直接核对 arXiv 原文、Meta/Google/TikTok 官方页面与财报 PDF；所有 `[镜像]`/`[摘要]`/`[二手]` 条目建议在有完整网络时按给出的 URL 复核，尤其是 Meta 2026Q2 的 +8.3%/+15.7%、TikTok Smart+ 的 52%/2.2x、Google AI Max 的 14%/27%、快手 UAX 80% 等数字。
