# Agent 调研：发展现状、未来趋势与内部研发提效思路

## 背景

我是 TikTok 推荐架构负责人，计划做一个内部 Agent 来提升研发效率。这个文件夹用来沉淀对 AI Agent 领域的调研，目标是回答三个问题：

1. Agent 技术和产业现在发展到了什么程度？
2. 未来 12 到 24 个月大概率会发生什么？哪些东西不值得自己做？
3. 对推荐系统研发团队来说，哪些 Agent 方向最值得先做？

## 专题列表

| 日期 | 专题 | 一句话结论 |
|---|---|---|
| 2026-10-06 | Agent 发展现状与研发提效 | 竞争重心从模型转向 harness；内部投入应集中在工具 MCP 层、私有评测与验证器、私有上下文、安全分级 |
| 2026-10-06 | AgentX 快手推荐自迭代Agent深挖 | 快手 AgentX 是"提案→生产代码→受护栏 A/B→harness 演化"闭环；业务数字为厂商自述、论文全文未能获取，需谨慎引用 |
| 2026-10-16 | 内部知识库构建更新与对话反馈评测 | 业界无人全自动闭环，反馈一律经人工策展；增量通道不传删除与权限，需全量对账；词法检索是第一公民，DeepSearch 只给复杂问题；配套设计方案、评测方案与可运行原型 |

## 使用方式

- 先读 `reports/` 下的综合报告，里面有结论和建议。
- 要开工建设时看 `design/`，要看机制跑起来是什么样就运行 `prototypes/knowledge-loop/run_demo.py`。
- 需要核实某个数字或论断时，到 `research_notes/` 对应主题的笔记中找原始来源。
- 后续新的调研请在 `research_notes/` 下新建一个主题文件夹，并在 `reports/` 下新增同名报告，不要覆盖旧的。
