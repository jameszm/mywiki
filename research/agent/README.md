# Agent 调研：发展现状、未来趋势与内部研发提效思路

## 背景

我是 TikTok 推荐架构负责人，计划做一个内部 Agent 来提升研发效率。这个文件夹用来沉淀对 AI Agent 领域的调研，目标是回答三个问题：

1. Agent 技术和产业现在发展到了什么程度？
2. 未来 12 到 24 个月大概率会发生什么？哪些东西不值得自己做？
3. 对推荐系统研发团队来说，哪些 Agent 方向最值得先做？

## 目录结构

```
research/agent/
├── README.md                      # 本文件
├── reports/                       # 综合报告（面向决策的最终产出）
│   └── Agent 发展现状与研发提效.md
└── research_notes/                # 分主题的原始调研笔记（含来源链接）
    └── Agent 发展现状与研发提效/
        ├── 01_技术范式与架构演进.md
        ├── 02_Coding_Agent格局与大厂内部实践.md
        ├── 03_推荐与ML研发场景的Agent应用.md
        ├── 04_企业落地工程体系_评估安全可观测成本组织.md
        └── 05_未来趋势与预测.md
```

## 使用方式

- 先读 `reports/` 下的综合报告，里面有结论和建议。
- 需要核实某个数字或论断时，到 `research_notes/` 对应主题的笔记中找原始来源。
- 后续新的调研请在 `research_notes/` 下新建一个主题文件夹，并在 `reports/` 下新增同名报告，不要覆盖旧的。
