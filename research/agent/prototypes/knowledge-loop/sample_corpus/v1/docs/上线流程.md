# 模型上线流程

排序模型从离线评估到全量的标准流程, 适用于所有 ranking 模型迭代。

## 流程总览

模型上线分三步: 离线评估达标 -> 小流量 A/B 实验 -> 全量发布。每一步都有明确的准入门槛, 未达标不得进入下一步。
整个流程在发布平台上以工单形式跟踪, 工单需要关联实验 id 与离线评估报告。

## 离线评估门槛

离线 AUC 相比线上基线提升 >= 0.1%, GAUC 不下降, 且在最近 3 天的样本上结论一致。
评估报告需要附在上线工单中。

## 小流量实验

按 A/B 实验平台指南创建实验, 流量 5%, 至少运行 7 天, 核心指标显著正向且护栏指标不劣化。

## 全量与回滚

全量发布前需要在发布平台填写回滚方案; 全量后观察 24 小时。
出现问题时按排序服务 runbook 的回滚步骤执行 `deployctl rollback`。

## 审批

全量需要架构评审 (architecture review) 与模型 owner 审批, 评审会每周二举行。
