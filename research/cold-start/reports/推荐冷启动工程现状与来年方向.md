# 可度量的探索正在取代冷启动流量补丁

截至 2026 年 10 月，推荐冷启动的工业落地已经从"给新物料固定保量、靠运营打补丁"转向四道可以工程化的工序：让新物料**可触达**（秒级进索引）、**可打分**（不依赖 ID 的内容代理）、**可分配**（按 item 学习的探索预算）、**可度量**（能看见语料效应与创作者供给效应的实验设计）。前两道已在头部公司普遍上线并公开收益：Meta Instagram Reels 把早期排序的 embedding 新鲜度从约 5 分钟压到约 20 秒、预测覆盖率从 96% 提到 100%、冷启互动 **+5–6%**；快手 GR4AD 让新物品由内容算出语义 ID 后**秒级**进入索引；抖音 Streaming VQ 把十亿级召回索引从 **1.5–2 小时**重建改成训练流中的实时分配；小红书 IDProxy 与 Pinterest Warmer for Less（参数只增 **5%**、新内容互动 **+10%**）把内容代理低侵入地接进既有排序。第三道只有 Google（按 item 学习"可被发现概率"分配曝光）、Pinterest（PinEqualizer 独立探索语料 + Thompson/UCB）和阿里（AliBoost，6 个月冷启动 **10 亿+** 新品）公开了机制，字节与快手都没有公开探索预算或保量规则；坊间流传的抖音/TikTok "300→3000→1 万播放"式流量池档位**没有任何官方出处**，各版本数字互相矛盾。第四道是 2026 年最大的新进展，也是最大的瓶颈：某大型短视频平台的 8 个月创作者消融显示生产探索使每创作者投稿 **+8.55%**，但观众侧 A/B 会因两臂共享语料而抵消这类效应、三周实验连效应符号都定不了，而常用的对称双边隔离本身又有不随平台规模消失的互动成本。生成式推荐是新的风险源：快手 OneRec-V2 在关闭缓存、全部请求走新模型的实验组中冷启视频播放 **−44.7%**，多篇诊断研究证明语义 ID 生成"可组合但不开放"，补救必须落在解码配额与码本更新上（快手 Multi-Decoder OneRec 用路由配额做到新内容冷启 **+2.09%**）。未来 12 个月的重点是探索预算模型化、生成式链路冷启护栏标准化和供给侧实验基础设施；对刚接手 TikTok 冷启动的工程负责人，公开证据支持的顺序是先建口径与可识别性，再补"可触达、可打分"这类低风险高确定性的基础设施，然后把探索分配模型化并做双冷隔离，再建供给侧实验能力，最后为生成式迁移预设冷启门禁。

## 全景：冷启动被拆成"可触达、可打分、可分配、可度量"四道工序

2025 年中以来最清晰的变化是，没有一家头部公司再把冷启动当成"一个冷启模型"来做。公开系统按工序分层：**可触达**靠索引与缓存基础设施（字节 Streaming VQ 与 MERGE、快手 GR4AD 的 SID 实时索引、Meta MFLI 与 Memory Layer），**可打分**靠对齐到 ID 空间的内容代理与成熟度门控（小红书 IDProxy、淘宝 SaviorRec、阿里国际 GateSID、Pinterest Warmer for Less、TikTok Live FLUID），**可分配**靠独立探索语料与后验预算（Google、Pinterest、阿里 AliBoost、快手路由配额），**可度量**靠长期 holdout、语料分片与创作者侧实验（Google user-corpus co-diverted、Pinterest 三层测量、2026 年的创作者供给与隔离成本两篇论文）。四道工序的成熟度差异很大：前两道收益确定、代价可控、公开案例多；第三道公开案例少且几乎都不给阈值；第四道刚刚出现可用的方法论，而它恰恰决定前三道的投入能不能被正确归因。

四类冷启对象的落地程度也极不均衡。下表按"已上线的主流做法 / 代表性公开收益 / 最大公开空白"概括，细节与来源见后续各节。

| 新内容（短视频/笔记/直播间） | 内容代理对齐 ID 空间；秒级索引与模型内缓存；"为新内容找用户"的反向召回；独立探索语料 + 后验分配 | Memory Layer 冷启互动 +5–6%（切片）；Next-User Retrieval DAU +0.0142%、投稿 +0.1144%（全站）；FLUID 冷启直播间观看 +2.05% | 探索流量占比、晋级/淘汰阈值、"上传→可推荐"端到端时延，均无任何平台公开 |

## 探索流量分配：预算从固定档位变成按 item 学习的后验

### 没有任何平台公开探索占比，预算成了模型的隐式输出

2025 年中以来**没有一家头部平台公开"新内容探索流量占总流量的比例"**，能找到的只有间接量级，且口径互不相同。Google 的探索论文正文（经搜索摘要，未核实）把问题描述为"把数十亿探索曝光分给数百万新 item"，并说明这是一套专用探索系统，新 item 只在专用流量内互相竞争（[arXiv 2505.09033](https://arxiv.org/abs/2505.09033)、[HTML 版](https://arxiv.org/html/2505.09033v1)）；一份搜索摘要归于 Google 的专利 US11887154B2 在示例中把约 10% 的请求导入探索桶（[Google Patents](https://patents.google.com/patent/US11887154)，受让人与权利要求未核实，且是专利示例而非生产配置）；快手冷启动团队早年的分享称"每天新视频达到千万量级"（[知乎转载](https://zhuanlan.zhihu.com/p/660797252)，约 2023 年，未核实）。用户侧唯一的外部测量是波士顿大学与华盛顿大学 2024 年的审计：新 TikTok 账号前 1,000 个视频中 30%–50% 基于已学到的兴趣（[arXiv 2403.12410](https://arxiv.org/abs/2403.12410)、[Tubefilter 报道](https://tubefilter.com/2024/03/21/how-tiktok-recommendation-algorithm-works-research/)，未核实）——这是用户侧探索口径，与 item 探索桶的请求占比完全不是一回事，两者都不能当作 TikTok 的生产配置。

更重要的是，公开系统已经不再把探索预算当成一个可配置的全局常数。Google 用 per-item 的可发现概率配合置信度参数决定每个新 item 的曝光量，Pinterest 让后验与实时曝光 UCB 自适应分配，快手把冷启生态目标写进奖励与路由配额——预算是模型或奖励的输出，而不是配置项。对标时追问"别人给了百分之几"没有意义，该追问的是"预算由什么机制决定、用什么指标验收"。

### 五类机制在链路上分工，而不是互斥

公开案例可以归为五类，2025–2026 的主流是组合使用。**学习式预算分配**回答"每个 item 总共该给多少"：Google 的 Item Level Exploration 学习"给定流量后 item 是否会变得可被发现"的概率模型，据此把曝光从"不需要帮助或帮不了"的 item 转向"再多一点曝光就能起来"的 item，摘要称已在大规模生产部署并显著提高新内容可发现性（[arXiv 2505.09033](https://arxiv.org/abs/2505.09033)）【已上线·未披露数字】；搜索摘要转述的正文细节是把它建模为 P(G=1 | 特征, 流量 Y) 的分类问题，再按置信度 CF 反解所需流量，并强调"实际用于数据收集的流量不必等于所需流量"这一标签构造细节（未核实）。配套的 Item-centric Exploration（RecSys 2025）把问题从"为用户找 item"翻转为"为新 item 找最优用户"，用 Beta 分布的贝叶斯控制在"预测的用户满意度"与"item 固有质量"之间筛选候选，线上冷启定向效率与用户对新探索内容的满意度显著提升（[arXiv 2507.09423](https://arxiv.org/abs/2507.09423)）【已上线·未披露数字】。

**不确定性驱动的 bandit** 回答"同一批候选里给谁多一点"。Pinterest PinEqualizer 自 2024 年起迭代上线，复现笔记转述的探索价值估计是后验均值 r̂ = (α·N + e)/(N + n)（模型先验 α、先验强度 N、正反馈 e、曝光 n），实时曝光 UCB 为 α/√(1+β·impressions)，搜索场景再乘相关性的 γ 次方以抑制不相关探索，另有基于主模型隐向量的 Neural Linear UCB；公开收益为新内容曝光累计 **+350%**、长期 holdout 中欠探索内容互动 Homefeed/Search/Related Pins 分别 **+37%/+13%/+27%**（[arXiv 2607.22518](https://arxiv.org/abs/2607.22518)、[daiwk 复现笔记](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2607.22518-pinequalizer/README.md)，数字未核实）【已上线·公开收益】。YouTube Music 用 SNGP 头输出均值与方差，排序分取 μ + β·σ，1 天内新发行内容 engagement **+4.33%**（[arXiv 2607.23749](https://arxiv.org/abs/2607.23749)、[daiwk](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2607.23749-youtube-freshness/README.md)，数字未核实）【已上线·公开收益】，作者承认它带来"可测的互动或多样性代价"但不给幅度。Meta 的 epinet 在 Facebook Reels 冷启召回阶段做 Thompson 采样，冷启内容曝光 **+17%**（[arXiv 2412.04484](https://arxiv.org/abs/2412.04484)，2024-12）【论文·未确认上线】，2025–2026 未见其生产状态的后续说明。NAVER WEBTOON 把 LLM 对评论的语义判断转成 Beta 伪计数 α = 1 + κp、β = 1 + κ(1−p) 作为 Thompson 先验，四周、每臂约 59.5 万用户的 A/B/C 中，性别先验总体 CTR +1.48% 不显著，但 **10–49 次曝光的冷启段 +9.51%**，而内容先验总体 **−5.68%**（[arXiv 2608.03382](https://arxiv.org/abs/2608.03382)、[daiwk](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2608.03382-llm-ts-prior/README.md)，数字未核实）【已上线·公开收益】——这是"坏先验本身就是可量化探索成本"的直接证据。

**分层 boost / 保量 / 配额**回答"从大盘切多少给冷启"，是坊间"流量池"在公开资料里唯一的正式对应物。阿里 AliBoost 用分层 boosting 结构让高潜力 item 快速获得曝光、对低潜力 item 最小干扰，配合在基础 CTR 模型上叠加微调的冷品潜力预测器和 item 侧出价式加权投放，"过去六个月部署于阿里主流平台，成功冷启动超过 10 亿新品，冷品 180 天内点击与 GMV 提升超过 60%"（[arXiv 2506.00954](https://arxiv.org/abs/2506.00954)）【已上线·公开收益】，但层数与晋级边界未披露。快手 Multi-Decoder OneRec 明确承认工业召回"按目标给召回路显式配额"，并在生成式召回里保留推理时的显式路由配额，生产 A/B 新内容冷启 **+2.09%**、人均时长 +0.37%、D7 留存 +0.19%（[arXiv 2607.26500](https://arxiv.org/abs/2607.26500)）【已上线·公开收益】；更早的 OneRec 技术报告用"目标占比 f + 奖励折扣 α"对某类内容做软配额，爆款搬运内容曝光 −9.59% 而时长持平（[arXiv 2506.13695](https://arxiv.org/abs/2506.13695)）【已上线·公开收益】。

**uplift / 因果**回答"把流量给边际收益最大的 item 或场景"。淘宝搜索 GrowthGR 用反事实推断量化单次交互带来的长期价值增量（ItemLTV），在生成式召回里显式平衡短期成交与长期成长，**新品 GMV +5.3%、整体搜索 GMV +0.3%**（[arXiv 2605.17994](https://arxiv.org/abs/2605.17994)）【已上线·公开收益】；Pinterest 用随机化日志学 doubly-robust uplift 决定是否触发购物召回通道，触发量 −85% 而关键购物会话持平（[arXiv 2607.14161](https://arxiv.org/abs/2607.14161)）【已上线·公开收益】；快手 HMUM 的异构多 treatment uplift 已全量，但未说明是否覆盖冷启扶持策略（[arXiv 2511.18997](https://arxiv.org/abs/2511.18997)）【已上线·未披露数字】。uplift 用于短视频新内容流量分配目前没有公开案例。**公平约束**只以验收指标存在（Pinterest 的成功创作者数、抖音的投稿数），约束式分配的工业案例为零。

这五类机制的合理分工是：学习式预算定总量，bandit 定内部顺序，配额定冷启份额的下限，uplift 定把份额投向哪里，公平指标做护栏。若 TikTok 现有机制是固定档位保量，公开资料指向的升级路径是 AliBoost 式"潜力预测驱动的分层 boost"→ Google 式"per-item 可发现性预算"→ Pinterest 式"去偏为主、显式探索为辅"，同时保留档位作为上限与可解释性兜底。

### 在链路哪一层做：serving 层加权会被学习环吃掉

YouTube Music 的六组线上实验给出了迄今最直接的"位置"结论：在持续训练的系统上，**serving 层的干预会被学习环中和**；架构去偏（IPS、可在服务时移除的 bias tower）减少流行度主导、改善多样性，但**不创造发现**；不确定性探索提升最大但有代价（[arXiv 2607.23749](https://arxiv.org/abs/2607.23749)）【已上线·公开收益】。这解释了为什么 Google 和 Pinterest 都把探索做成"独立流量或独立语料 + 训练期去偏"，而不是在主排序分上加一个 boost。第二个位置约束是召回：排序 boost 救不了"根本没被召回"的新内容。Meta MFLI 用带新鲜度 facet 的学习式索引直接查表，7 天 A/B 超新鲜内容 **+221%**、低播放量内容 **+279%**、头部 −2%（[arXiv 2602.16124](https://arxiv.org/abs/2602.16124)、[daiwk](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2602.16124-mfli/README.md)，数字未核实）【已上线·公开收益】；字节 MERGE 的动态索引使新内容曝光 **+0.59%～+7.64%**、低播放内容曝光 +1.49%～+11.87%、物料存活率 +45.04%（[arXiv 2601.20199](https://arxiv.org/abs/2601.20199)）【已上线·公开收益】。第三个是页面结构："Where to Explore"在一个 1 亿+月活的流媒体 TV 平台上找出滚动深度中互动低、触达高的位置，放一行随机内容，A/B 显示业务指标不受损且回收的无偏数据接入召回后显著提升互动（[arXiv 2512.14733](https://arxiv.org/abs/2512.14733)）【已上线·未披露数字】。对 TikTok 这样的单列沉浸式 feed，它对应的是插入位与混排配额，成本可以按"插入位的机会成本"量化，比全局 boost 可控。Pinterest PinEqualizer 则在语料选择、召回、精排、效用层逐级检查 fresh 内容的输入占比与存活率，是"全漏斗"做法的公开样板。

### 晋级靠置信度而非固定播放量，"新"的窗口从日历时间转向模型可见度

公开的晋级规则只有机制、没有阈值。Pinterest 是"达到互动阈值则毕业进入利用语料，否则回到探索语料"，Google 是"可发现概率达到置信度"，SocRipple 是"早期互动用户的 KNN 扩散"（[arXiv 2508.07241](https://arxiv.org/abs/2508.07241)）。共同点是**后验或置信度驱动，而不是固定次数**——固定的"前 N 次曝光看 CTR"会被内容类型差异与位置偏置污染，所以 Pinterest 先按内容类型做 fresh-aware 校准再比阈值。"新"的时间窗口各家差异很大：小红书 IDProxy 以 **<24 小时**定义新笔记，YouTube Music 看 **1 天内**新发行，Pinterest 用 **28 天**，AliBoost 以 **180 天**衡量冷品成长，NAVER 把 **10–49 次曝光**作为最受益段；Pinterest Warmer for Less 更进一步，把冷启 item 定义为"在训练数据中出现很少"（[arXiv 2512.17277](https://arxiv.org/abs/2512.17277)），即按模型可见度而非日历定义——这对持续训练系统更贴合"模型是否已经学到该 item"。

去偏与显式探索之间存在替代关系。daiwk 在 MovieLens-1M 上复现 PinEqualizer 机制时，三组验证都选出 UCB 系数 α=0，复现者的结论是"去偏模型已把 fresh 流量推得很高，额外 UCB 只会恶化验证目标"（[daiwk](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2607.22518-pinequalizer/README.md)，公开数据复现，不代表线上）。学术侧另有两条警告：冷启模型以 warm CF 模型为监督会**继承并放大流行度偏置**，"内容像爆款"的冷 item 被显著高估（[arXiv 2510.11402](https://arxiv.org/abs/2510.11402)）【仅研究】；线性 bandit 的离线评估在 90% 以上数据集上偏向"不探索"（[arXiv 2507.18756](https://arxiv.org/abs/2507.18756)）【仅研究】。含义是：去偏模型上线后，探索预算必须重新评估，而且不能用离线指标评估。

### TikTok 与抖音：官方只有原则，"流量池"档位只有坊间版本

TikTok 的官方公开口径只有原则性表述，且本次只能经搜索摘要读到【平台政策说明】：2020 年新闻室文章称"粉丝数和账号是否有过高表现视频都不是推荐系统的直接因素"，强信号（看完一条较长视频）权重高于弱信号（观众与创作者同国家）；透明中心称只有通过审核的视频进入可推荐池，"刚上传或审核中的视频可能不具推荐资格"，且一般不会连续推荐同一创作者或同一音频的两条视频（[TikTok Newsroom](https://newsroom.tiktok.com/en-us/how-tiktok-recommends-videos-for-you)、[TikTok 透明中心](https://www.tiktok.com/transparency/en-us/recommendation-system/)）。抖音 2025-03-30 上线"安全与信任中心"并公开推荐原理，媒体转述的核心是"预测用户行为概率 × 不同行为的价值权重"、"流量越高的内容经过评估的次数越多，标准也越严格"、平台"不会硬推"，报道未给出新视频初始推送规模、测试池大小或晋级条件（[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_30665269)、[新华网](https://www.xinhuanet.com/tech/20250417/9b2e3622d8764c408c2b667bf73d1d29/c.html)）【平台政策说明】。

"先给小批量用户测试、达标再逐级放大"的流量池叙事来自运营圈与 SEO 页面【坊间说法·非官方】：一个版本称首轮约 300 播放、二轮约 3,000、三轮 1.2 万–5 万并自注"不一定那么精确"，另一版本称 200–500 / 3,000–5,000 / 1–2 万（[digitaling](https://www.digitaling.com/articles/669283.html)、[人人都是产品经理](https://www.woshipm.com/it/6307166.html)）；TikTok 侧的"初始测试组 200–500 人""前 3 秒 70% 留存"出自创作者帖子与 TikTok Discover 的 SEO 页（[TikTok Discover](https://www.tiktok.com/discover/does-tiktok-show-your-video-to-first)），还有说法称首轮投给粉丝，彼此矛盾。没有找到官方确认或否认固定播放量门槛的材料。一个合理的推断是，抖音公开的"流量越高评估越多、标准越严"的**审核分层**在结构上与"逐级晋级"同构，可能是坊间说法的来源之一，但它描述的是安全审核而非推荐探索预算。对内部工程师，这些档位唯一的价值是作为"创作者心智模型"——它会影响创作者对初始曝光的预期与投稿行为。快手早年的分享是唯一一份中国短视频平台的冷启工程自述（约 2023 年，未核实）：冷启只干预新视频低播放量阶段、整体探索成本保持稳定，召回侧用从视频出发找兴趣人群的 I2U 反向检索，并把 CTR 预估改为 Beta 分布兼顾均值与方差，使"0 播放内容的有效透出率提升 22%"（[知乎转载](https://zhuanlan.zhihu.com/p/660797252)）。

## 新内容建模：内容代理对齐 ID 空间，生成式推荐只能"组合式"触达新内容

### 内容代理 + 成熟度门控成为排序侧标配

2025 年中以来公开上线的方案里，没有一家把"冻结多模态向量直接喂排序"当作冷启主方案。共同模式是：冻结 MLLM/CLIP 编码 → 用行为监督**对齐到协同或 ID 空间** → 作为 ID 的代理或补充进入现有排序 → 用显式的成熟度门控或掩码在冷/热之间切换。小红书 IDProxy 用冻结 MLLM 生成 proxy embedding，先用对比损失对齐 warm item 的 ID embedding，再从多层表征抽多粒度特征、经残差门控后作为"类 ID 特征"注入排序并端到端联合训练，新 item 的 proxy 离线预计算、排序时查表；已部署于发现页内容流与展示广告，复现摘要转述 <24 小时新 item 的 AUC 增益 +0.23–0.32%，约为全局的 2 倍，内容流时长 +0.22%、广告主价值 +1.93%（[arXiv 2603.01590](https://arxiv.org/abs/2603.01590)、[memgrafter 摘要](https://github.com/memgrafter/research-digests/blob/main/ml_research_analysis_2026/2603.01590_idproxy-cold-start-ctr-prediction-for-ads-and-recommendation-at-xiaohongshu-with-multimodal-llms_20260401_024856.md)，百分比未核实）【已上线·公开收益】。阿里国际 GateSID 按 item 成熟度（交互数、上架时长）门控语义与协同信号：冷品加强语义-行为一致性约束、热品放松以保留协同信号，线上 GMV +2.6%、CTR +1.1%，额外延迟 **<5 ms**（[arXiv 2603.22916](https://arxiv.org/abs/2603.22916)，部分数字经复现笔记转述，未核实）【已上线·公开收益】。淘宝 SaviorRec 用 co-click 对比微调多模态编码器、RQ-VAE 量化成 SID 后索引一个零初始化的残差对齐码本，冷启 clicks +13.21%、长尾 orders +13.44%（[arXiv 2508.01375](https://arxiv.org/abs/2508.01375)，数字未核实）【已上线·公开收益】；快手电商搜索 SMILE 用 RQ-OPQ 同时量化内容与协同信息，item CTR **+1.66%**、订单 **+2.17%**（[arXiv 2510.12604](https://arxiv.org/abs/2510.12604)）【已上线·公开收益】；淘宝搜索广告 MIM 专门设计实时推断模块，新 item 一上线就推出其多模态 embedding 并同时写入训练表与参数机（[arXiv 2502.00321](https://arxiv.org/abs/2502.00321)）【已上线·公开收益】。

Pinterest Warmer for Less 是对精排冷启改造最具检查表价值的公开工作：从真实流量诊断出四个根因并各给一个轻量对策——冷 item 是少数所以改进必须极省（合计只增 **5%** 参数）；冷 item 只有非历史特征而模型轻视它们（给非历史特征加残差连接）；冷 item 预测分系统性偏低（冷/非冷分数正则）；冷 item 标签稀疏（manifold mixup）。合计使新内容互动 **+10%**，整体互动与成本不受损，服务 5.7 亿用户（[arXiv 2512.17277](https://arxiv.org/abs/2512.17277)）【已上线·公开收益】。同一公司的 MESH 指出，为覆盖 fresh 与长尾，现代系统常退化成一个碎片化的专用召回模型"动物园"，根因是模型容量增益在不同内容层上不均等；用按特征域划分的模块化架构与门控偏差修正统一之，fresh-item repins **+5.5%**、留存 +0.46%（[arXiv 2607.12392](https://arxiv.org/abs/2607.12392)）【已上线·公开收益】。PinFM 的教训同样直接：20B+ 参数的用户序列基础模型接入首页排序后 fresh 保存约 −5%，加入"微调时 10% 概率随机化候选 ID"与"对 T 天内新内容做模块输出 dropout"后转为约 +10%，线上 HF Fresh Saves **+5.70%**（[arXiv 2507.12704](https://arxiv.org/abs/2507.12704)，全文）【已上线·公开收益】——**任何更大的模型接入排序前都要先测冷启切片**。

"新 ID 怎么预热"在工业里被基础设施改写了。经典的"从内容生成 ID embedding"路线（Meta-Embedding 2019、MWUF 2021、CVAR 2022）与 2025–2026 的扩散式生成（CSDM、DiffCold）在学术上仍活跃，但没有看到上线案例。上线的替代形态有三：代理特征注入（上述 IDProxy/SaviorRec/GateSID）；LLM 当超网络直接生成冷启 CTR 线性预测器的逐特征权重（LLM-HYPER，美国头部电商，线上"大幅缩短冷启动期"，[arXiv 2604.12096](https://arxiv.org/abs/2604.12096)）【已上线·未披露数字】；以及让新 ID 拿到干净槽位与秒级新鲜度——Meta MPZCH 用多探针零碰撞哈希让新 ID 获得专属槽位、驱逐时同时重置权重与优化器状态，新视频曝光 +0.83%（[arXiv 2602.17050](https://arxiv.org/abs/2602.17050)，数字未核实）【已上线·公开收益】；Meta Memory Layer 把服务时的 item embedding 缓存改成与模型共训的模型内 KV 表，作者与 topic 等 always-on 属性覆盖尚未入缓存的 item，预测覆盖率 96%→100%、新鲜度约 5 分钟→约 20 秒、最新内容召回 >2 倍、冷启互动 **+5–6%**、训练与发布算力 −30%（[arXiv 2607.25110](https://arxiv.org/abs/2607.25110)）【已上线·公开收益】。只要新 ID 能在秒级拿到干净槽位并在 20 秒内被写回，"预热"就更多靠真实早期反馈加内容代理，而非生成一个"假 ID 向量"。

学术侧两条警告直接影响工程设计：内容→协同映射会继承并放大热门偏差（[arXiv 2510.11402](https://arxiv.org/abs/2510.11402)）【仅研究】；冷/热表征存在"跷跷板"，提升冷品常伤热品，根因是 warm embedding 在行为流形、cold embedding 在语义流形（DiffCold，[arXiv 2606.12245](https://arxiv.org/abs/2606.12245)）【仅研究】。这解释了工业方案为何普遍加分数正则、分内容类型校准和成熟度门控。

### 反向召回与冷品去噪：把"user→item 打分"翻成"item→user 检索"

"为新内容找用户"是 2025–2026 冷启召回的工业主线，三条路线都已上线。抖音 Next-User Retrieval 以 item 特征（ID、类目）为前缀 prompt、最近互动的最多 50 个用户 ID 为序列，生成"下一个最可能互动的用户"向量，经 HNSW 与请求用户匹配；去掉前缀 prompt 使 Recall@20 −14.15%，说明零交互时主要靠 item 特征；线上 **DAU +0.0142%、投稿 +0.1144%**，摘要把冷启成败与"高质量新 item 能否转为热门、创作者能否获得反馈并长期留存"绑定（[arXiv 2506.15267](https://arxiv.org/abs/2506.15267)）【已上线·公开收益】。阿里 FilterLLM 扩展 LLM 词表加入用户 token，一次前向输出冷品对全体用户的交互分布，相对逐对判断的 ColdLLM 效率 34.75 倍，处理超 10 亿冷品（[arXiv 2502.16924](https://arxiv.org/abs/2502.16924)）【已上线·公开收益】，复现笔记转述的线上 GMV +10.86%、推理时间 −97.12% 未核实。SocRipple 先用创作者社交关系做定向首轮曝光、再基于早期互动做 KNN 扩散，冷启分发 **+36%** 且互动率不降（[arXiv 2508.07241](https://arxiv.org/abs/2508.07241)，"a major video platform"，第三方归为 Meta）【已上线·公开收益，平台未具名】。快手 DualRec（WWW 2025 Companion）则把"为每个 item 找最合适的用户"做成独立的创作者侧推荐系统，并加入用户可用性计算，已在 Kwai 上线（[arXiv 2502.20497](https://arxiv.org/abs/2502.20497)）【已上线·未披露数字】。这些路线的全站收益都很小，真正的目标是创作者反馈与供给。

早期反馈本身更脏。快手 DIF 发现冷品更易受标题党与位置偏差噪声影响，而基于高 loss 的通用去噪在冷启场景失效；它用内容相似的 warm item 推断伪标签、按相似度建模置信度、用相对熵与冷启状态估计标签不确定性做样本级纠正，已部署于快手并"在冷启场景显著改善多项商业指标"（[arXiv 2606.19658](https://arxiv.org/abs/2606.19658)）【已上线·未披露数字】。冷启探索流量的首批观众分布与常规流量不同，**毕业阈值应当用去噪后的信号**，否则会把标题党推进利用语料。

### 语义 ID 的冷启收益真实但有边界

SID 对冷启的收益是真实的，且集中在新内容切片：头条 R3-VAE 用其 SID 替换 CTR 模型的 item ID 后内容冷启指标 **+15.36%**（[arXiv 2604.11440](https://arxiv.org/abs/2604.11440)）【已上线·公开收益】；微信 Tlow 的 token-ID 召回全局 CTR +10.32%、新 item **+11.64%**（[arXiv 2608.24176](https://arxiv.org/abs/2608.24176)）【已上线·公开收益】；快手 QuaSID 在电商 5% 流量上冷启召回完成订单最高 **+6.42%**（[arXiv 2603.00632](https://arxiv.org/abs/2603.00632)）【已上线·公开收益】；Google 用 SID 替代 Shorts 的 video ID、序列从 800 扩到 2,000，freshness 指标 +6.81%（[arXiv 2606.07546](https://arxiv.org/abs/2606.07546)，数字未核实）【已上线·公开收益】；Spotify GLIDE 新节目发现 **+14.3%**（[arXiv 2603.17540](https://arxiv.org/abs/2603.17540)）【已上线·公开收益】；字节 TRM 按物品年龄分层报告 <1 天新品 AUC +0.06%、>7 天老品 +0.11%（[arXiv 2601.22694](https://arxiv.org/abs/2601.22694)）【已上线·公开收益】。排序侧主流是"SID + ID 双用"而非纯 SID：短视频搜索的 SID-Coord 用目标感知的 HID–SID 门控在记忆与泛化之间自适应，搜索长播率 +0.664%（[arXiv 2604.10471](https://arxiv.org/abs/2604.10471)）【已上线·公开收益】；真正去掉候选侧 ID 的只有短生命周期场景——TikTok Live FLUID 用 SigLIP2 与 Qwen3-Embedding 编码 2 分钟切片、4 层 RQ-KMeans 得到切片级与房间级码，候选侧完全去 ID，在线增量训练下用三阶段 warmup 稳定切换，冷启直播间观看 **+2.05%**（[arXiv 2605.21832](https://arxiv.org/abs/2605.21832)）【已上线·公开收益】。

边界同样清楚。碰撞治理的冷启收益有限，快手 OneMall 把碰撞率从 36% 降到 11% 只换来 HR@50 从 33.9% 到 35.4%（[arXiv 2601.21770](https://arxiv.org/abs/2601.21770)，数字经二手转述，未核实）；更有用的是**动态码本与新 item 的秒级分配**：快手的单层大语义码本加协同消歧 token，引入时间衰减、EMA 中心更新和"按曝光加权惩罚 SID 变更"（热门 item 的 SID 更难被改动），2.5% 生产流量主消费指标 +0.792%、解码 FLOPs −48%（[arXiv 2608.21012](https://arxiv.org/abs/2608.21012)）【已上线·公开收益】；快手直播广告 TAGR 周期性刷新每个活跃广告的 SID 同时保持层次 token 词表稳定，收入 +16.1%（[arXiv 2608.24034](https://arxiv.org/abs/2608.24034)）【已上线·公开收益】。评测口径也有坑：在四个数据集五种 tokenizer 上，卷入碰撞的 item 最高 30.5%，**SID 级命中把 Hit@10 高估最多 103%**（[arXiv 2605.25330](https://arxiv.org/abs/2605.25330)）【仅研究】——冷启评估必须用 item 级命中。

### 生成式主链路会吞掉冷启流量，补救必须落在解码与配额

2026 年的三组证据把"生成式推荐天然利好冷启"的说法拆成了两半。机制上，Meta 与 UCSD 的研究显示生成式推荐在需要"泛化"的样本上优于 ID 模型（Office 数据 NDCG@10 +58.8%，数字经二手摘要，未核实），但 item 级泛化大多可归结为 token 级的前缀记忆（[arXiv 2603.19809](https://arxiv.org/abs/2603.19809)）【仅研究】；Snap 与 KAIST 发现 LLM 型生成式推荐的增益大部分来自可由一跳记忆预测的用户（[arXiv 2606.17276](https://arxiv.org/abs/2606.17276)）【仅研究】；阿里 ColdSID 在绝对时间协议下诊断出 SID 模型偶尔能到达"由已观测 token 与前缀支撑"的新 item，但对**未见原子 token 与无支撑的 SID 路径几乎无能为力**，结论是"可组合但不开放"（[arXiv 2607.21101](https://arxiv.org/abs/2607.21101)）【仅研究】；GenRecEdit 报告生成式模型的冷启准确率可降到接近零（[arXiv 2603.14259](https://arxiv.org/abs/2603.14259)）【仅研究】；含快手作者的 DREAM 认为"离线 tokenization 对冷 item 的早期静态承诺，而非模型容量，才是根本瓶颈"（[arXiv 2606.06947](https://arxiv.org/abs/2606.06947)）【仅研究】；统一协议的复现研究显示 item 冷启系统性比 user 冷启难（Recall@10 差距常超 20%，数字经二手摘要，未核实），扩大模型与 RL 微调都不能可靠缩小差距（[arXiv 2603.29845](https://arxiv.org/abs/2603.29845)）【仅研究】。

工业数据点只有一个，但足够刺眼：OneRec-V2 技术报告在 5% 实验流量之外另开 1% "关闭缓存、全部请求走 OneRec-V2"的组，相对 V1 互动类指标 +9.6%～+29.2%，但快手主站与极速版 **冷启视频播放 −44.704% / −36.730%、簇密度 +11.692% / +7.933%**，作者称之为"需要在未来方向中慎重考虑的关键挑战"，且未给出补救（[arXiv 2508.20900](https://arxiv.org/abs/2508.20900)，全文）【已上线·公开收益（含负向生态数字）】。簇密度上升与解码集中到高概率 SID 前缀一致，说明问题出在"生成分布过尖"，补救必须发生在解码/采样层或奖励层，仅靠内容侧 SID 泛化不够。一年之后快手 Multi-Decoder OneRec 用推理时显式路由配额把新内容冷启做到 +2.09%——这是对"保量会在生成式时代消失"的直接反证：保量以配额形式进入了解码器。Google/YouTube 的 STATIC 把前缀树压成 CSR 稀疏矩阵，在加速器上做严格受约束的生成式召回，摘要举例的约束就是"强制内容新鲜度"，每步 0.033 ms、占推理时间 0.25%，称为首个生产规模的严格受约束生成式召回（[arXiv 2602.22647](https://arxiv.org/abs/2602.22647)）【已上线·公开收益】。TikTok 的 X-Rec 走另一条路：在连续 embedding 空间做 flow matching 生成检索触发向量再做 ANN，吞吐为 SID 自回归的 3.46 倍（[arXiv 2609.29180](https://arxiv.org/abs/2609.29180)）【已上线·公开收益】，新内容无需码本分配，但压力转回 ANN 的流式插入。

### LLM 的位置在离线产先验，而非在线排序

所有上线案例里，LLM 对新内容最"值钱"的产物都是可离散化、可校准的结构化输出：token、标签、属性、先验计数、线性权重、用户分布（FilterLLM、LLM-HYPER、NAVER、TRM 的域内 captioning、小红书 TagLLM 的冷启场景 PV CTR **+32.37%**，[arXiv 2603.21481](https://arxiv.org/abs/2603.21481)【已上线·公开收益】）。用 LLM 直接做冷启排序仍停在"某些情况下优于生产模型"：Netflix 的推理式微调模型在部分场景比生产排序高最多 8%（[arXiv 2511.18261](https://arxiv.org/abs/2511.18261)）【论文·未确认上线】。反向证据更多：同条件下文本 embedding 模型优于 LLM 重排（[arXiv 2512.13001](https://arxiv.org/abs/2512.13001)）【仅研究】；冷启场景的 cross-encoder 重排把推荐集中到 **3 个 item**（随机基线 497 个）（[arXiv 2604.16318](https://arxiv.org/abs/2604.16318)）【仅研究】；一个欧洲电商短视频流平台（疑为 Zalando，未核实）的 VCG 发现生成式 LLM embedding 在召回中出现空间坍缩，判别式 CLIP 更好，线上深度完播 +50%（[arXiv 2606.19627](https://arxiv.org/abs/2606.19627)）【已上线·公开收益】。成本方面没有任何平台公开"每条新视频的 MLLM 推理成本与时延"；唯一外部数据点是学术审计用 Gemini 2.5 Flash（8 帧 + 文本）标注约 3,700 条 TikTok 视频总花费约 50 美元（[arXiv 2608.17583](https://arxiv.org/abs/2608.17583)）【仅研究】。

## 新用户与低活用户：跨域实时行为胜过静态画像，低活用户不承担探索

头部短视频平台"新用户前几次会话推什么"的公开描述，仍然只有 TikTok 2020 年的那一套【平台政策说明】：系统从新用户表达的兴趣开始，跳过兴趣选择则给出"热门视频的泛化 feed"，首轮点赞、评论、重播启动个性化；语言、国家、设备类型等设置"权重较低，因为不是用户直接表达的偏好"（[TikTok Newsroom](https://newsroom.tiktok.com/en-us/how-tiktok-recommends-videos-for-you)）。2025 年中以后没有任何短视频平台发表新用户首屏策略的论文，新用户收益几乎都作为通用模型升级的分组分析顺带报告：腾讯 TGR 的推理 token 方案报告新用户曝光→转化 **+13.09%**（[arXiv 2609.00986](https://arxiv.org/abs/2609.00986)）【已上线·公开收益】，百度 UNIQUE 统一召排在"新用户与高活用户改善显著"（[arXiv 2609.23718](https://arxiv.org/abs/2609.23718)）【已上线·公开收益】，LinkedIn 的 LLaMA-3 双塔召回对缺少社交连接的新会员收益显著（[arXiv 2510.14223](https://arxiv.org/abs/2510.14223)）【已上线·未披露数字】。新用户专用建模的工业共识可以从快手 POSO（2021）一路串到 2026：不是单独训一个新用户模型，而是在共享主模型里给新用户与低活用户单独的门控、专家或先验——POSO 发现新用户样本不足 5%、"新用户指示特征"在训练中被淹没，用分桶累计曝光数生成个性化门控后新用户观看时长 +7.75%、留存 +1.52%（[arXiv 2108.04690](https://arxiv.org/abs/2108.04690)，背景）。

信号的价值排序在 2025–2026 有了清晰的量化。一篇大规模广告排序论文把用户的自然流行为量化成跨域 SID 喂给广告 CTR 模型：由用户资料文本生成的 SID 只带来 +0.036% AUC，活动微调的 LLaMA 用户 embedding +0.107%，直接 feed 行为 embedding **+0.213%**，**近零广告历史用户段最高 +1.522%**（[arXiv 2606.01396](https://arxiv.org/abs/2606.01396)）【论文·未确认上线】——"行为丰富度决定迁移质量"。同公司跨域迁移已大规模上线：快手 RGCD-Rep 用 MLLM 推理蒸馏学习短视频→直播的可迁移表征，全量服务 4 亿+日活（[arXiv 2606.04448](https://arxiv.org/abs/2606.04448)）【已上线·未披露数字】，搜索摘要称冷启用户增益大于活跃用户（未核实）；YouTube TokenMinds 用共享 SID 词表把长、短视频用户行为统一进一个用户模型并全量（[arXiv 2606.25147](https://arxiv.org/abs/2606.25147)）【已上线·公开收益】；Meta SCALR 把源域事件翻译成目标域合成交互做训练增强（[arXiv 2606.00282](https://arxiv.org/abs/2606.00282)，线上 A/B 显著但无数字）【已上线·未披露数字】。MAML 式元学习在十亿级流式系统里没有上线案例，工业形态已经退化为用户组先验、门控与不确定性策略。LLM 在用户冷启的落地形态是"离线或近线生成 + 蒸馏 + 异步服务"：淘宝 RecGPT-V2 GPU 消耗 −60%、CTR +2.98%（[arXiv 2512.14503](https://arxiv.org/abs/2512.14503)）【已上线·公开收益】，Google 在十亿用户视频平台上服务时实时生成自然语言兴趣 persona（[arXiv 2606.12198](https://arxiv.org/abs/2606.12198)）【已上线·未披露数字】；对低活用户最有证据的用法是让稀疏用户借稠密用户的统计量，淘宝 ChoirRec 用 LLM 构造跨活跃度的语义用户组，低活用户订单 **+7.24%**（[arXiv 2510.09393](https://arxiv.org/abs/2510.09393)）【已上线·公开收益】。一篇生产流媒体论文提醒 LLM 自然语言画像"显著更贵"，只在特定用户类型上值得（[arXiv 2609.27183](https://arxiv.org/abs/2609.27183)）【论文·未确认上线】。

低活用户是比新用户热得多的话题，2026 年的工业趋势是把活跃度当作**策略分流变量**而非特征。一篇来自"大型短视频与直播平台"的论文（共同作者与 FLUID 重合，机构推断为 TikTok 直播，未核实）用模型不确定性对低活用户做风险规避的去加权、只对高活用户做 UCB 探索，低活用户留存（活跃小时）与优质观看时长占比显著提升（[arXiv 2605.17788](https://arxiv.org/abs/2605.17788)）【已上线·未披露数字】；学术侧也发现交互历史少的用户在探索上"更早饱和"，统一探索强度会不成比例地伤害他们（[arXiv 2604.16419](https://arxiv.org/abs/2604.16419)）【仅研究】。这构成了公开资料中唯一被明确隔离的风险组合——**"双冷"（低活/新用户 × 冷启内容）**：低活用户不承担探索。借稠密用户的另一条路线是快手 MARS，为每个低活用户检索并浓缩最相似高活用户的行为序列做增强，全量部署（[arXiv 2509.01184](https://arxiv.org/abs/2509.01184)）【已上线·未披露数字】，搜索摘要称低活分组人均时长 +0.728%，并把冷启/长尾视频曝光作为生态检查项（未核实）。

留存在公开文献里几乎没被当作新用户的独立目标，而是通过三种代理落地：历史稀少用户上更可靠的满意度信号——Retentive Relevance 问卷（作者按姓名推断为 Meta）在预测次日留存上显著优于互动信号，"尤其对历史互动有限的用户"，其代理模型接入排序最后一级（[arXiv 2510.07621](https://arxiv.org/abs/2510.07621)）【已上线·未披露数字】；Pinterest 离线筛选"早期可观测且预测未来留存"的会话级行为作为下游奖励（[arXiv 2607.14192](https://arxiv.org/abs/2607.14192)）【已上线·未披露数字】；以及推送——抖音 STEPS 自触发智能体推送全量 10 亿+用户，活跃天数 **+0.2843%**、推送权限关闭率 **−1.9089%**、过滤智能体减少 79.42% 算力（[arXiv 2608.01949](https://arxiv.org/abs/2608.01949)）【已上线·公开收益】。全平台级留存的可检出变化只在 0.02%–0.3%，新用户分组实验要么需要很长窗口，要么只能看中间代理。

合规正在把新用户的可用信号按地区分叉。欧盟 DSA 下 TikTok 欧洲用户可关闭 For You 个性化，关闭后显示所在地区与全球的热门视频（按偏好语言），13–17 岁用户不再基于站内外活动投放个性化广告（[Verdict](https://www.verdict.co.uk/tiktok-announces-new-features-to-appease-eu-digital-services-act/)，2023，未核实）【平台政策说明】；2026 年欧盟委员会对 TikTok 未成年人账号设置发出初步认定（[Engadget](https://engadget.com/2223242/eu-says-tiktok-hasnt-done-enough-to-ensure-minors-safety)，非终裁，未核实）；学术审计发现 TikTok 对正式广告形式上遵守未成年人画像禁令，但带货与未披露推广内容仍呈强兴趣画像（[arXiv 2603.05653](https://arxiv.org/abs/2603.05653)）【仅研究】。含义是**"地区 + 语言热门"的非个性化 feed 应被当作一等公民路径优化**，而不是降级分支。新市场冷启的公开工程证据集中在电商：跨国生成式推荐 CMRec 用共享语义码本做"跨国代码混合"，让数据稀疏国家受益而不伤数据丰富国家，广告收入 +1.77%、订单 +2.64%（[arXiv 2609.28972](https://arxiv.org/abs/2609.28972)）【已上线·公开收益】；Coupang 用多语言 LLM 解决新市场相关性冷启，缺陷率 **−45.8%**（[arXiv 2509.01566](https://arxiv.org/abs/2509.01566)）【已上线·公开收益】；Adobe Express 证明只看点击的统一模型会把美国热门内容过度分发到增长市场，必须显式做地区感知加权（[arXiv 2605.11272](https://arxiv.org/abs/2605.11272)）【论文·未确认上线】。TikTok 侧只有产品线索：2025-12 在英法意德上线按位置展示本地内容的 Nearby Feed（[TechCrunch](https://techcrunch.com/2025/12/04/tiktok-rolls-out-a-nearby-feed-to-display-local-content-in-select-countries/)）【平台政策说明】。没有任何平台公开"新地区上线时区域模型 vs 全球模型"的决策。

## 创作者冷启动：探索的价值在供给侧，观众侧实验看不见

2025 年中至 2026 年 10 月**没有任何平台发表"创作者级冷启动"的专门工业论文**。公开工业系统里探索单位是 item，创作者只以三种方式进入：作为特征（PinEqualizer 的内容类型 × 用户年龄交叉、淘宝直播 SSRLive 的主播静态 SID，[arXiv 2606.06970](https://arxiv.org/abs/2606.06970)）、作为首轮受众选择（SocRipple 的创作者社交图、DualRec 的用户可用性）、作为评估目标（Next-User Retrieval 的投稿数）。唯一明确"先选创作者再选视频"的两层 Thompson 采样是 Meta 2023 年的 PIE（[arXiv 2304.06844](https://arxiv.org/abs/2304.06844)，背景，细节未核实）。后排序去偏是已上线的间接手段：YouTube LAFB 在后排序阶段做轻量的去熟悉度偏置，A/B 中新颖观看时长份额上升、"新兴创作者曝光改善"、总观看时长稳定，"已在 YouTube 推荐系统的后排序阶段上线"（[arXiv 2602.07987](https://arxiv.org/abs/2602.07987)）【已上线·未披露数字】。

2026 年最重要的证据来自一篇平台未具名的论文 **Content Exploration Beyond the Feed**（"a major short-video platform"）。它指出"在许多短视频平台上，探索是新视频触达观众的主要途径"，而已发表的预算目标都忽略了创作者响应；8 个月的创作者侧消融显示，相对"最低保底"，生产探索使**每创作者投稿 +8.55%、至少投稿一次的创作者 +7.10%**；预算不变的重新分配能提高创作者参与且短期观众侧无可检测变化；一年期观众侧消融显示探索使视频观看 **+1.74% 但观看时长 −2.13%**（[arXiv 2608.29430](https://arxiv.org/abs/2608.29430)）【已上线·公开收益（平台未具名）】。这组数字第一次把"探索预算的价值主要在供给侧"量化了，也坦白了它在观众侧的真实代价。Pinterest 是唯一把创作者结果纳入冷启汇报的美国公司：28 天"毕业"内容语料 +41% YoY、成功内容提供者 **+99% YoY**，"成功"的定义未公开（[daiwk](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2607.22518-pinequalizer/README.md)，未核实）。

建模上，创作者与内容冷启的差异有五点。时间尺度不同：内容冷启以小时、天计，创作者冷启以周、月计，且受语料周转率约束。目标不同：内容侧是可发现性与早期互动，创作者侧是投稿、持续投稿、留存。特征不同：创作者历史是新内容最强的先验——音乐研究 ACARec 把新曲冷启重定义为"半冷启"（多数新曲来自有历史的艺人），用艺人目录生成新曲的 CF embedding，Recall/NDCG 比纯内容基线翻倍以上（[arXiv 2604.07090](https://arxiv.org/abs/2604.07090)）【仅研究】，短视频可直接类比为"创作者目录注意力 + 内容多模态表征"；而更新频率、垂类一致性作为特征的量化证据为零。噪声不同：冷 item 反馈更脏（DIF），创作者级聚合可作去噪先验。主体性不同：创作者会策略性响应分发——势博弈分析显示多创作者争夺同一受众时均衡下几乎所有人都会"最大化夸张"（[arXiv 2502.01127](https://arxiv.org/abs/2502.01127)）【仅研究】，因此若使用创作者侧信号，更适合作为探索预算的输入而非排序特征，以降低被博弈的收益。

公平性方面，外部审计给出两条硬证据。Bluesky 自定义 feed 的同文本配对审计显示，33% 的配对中一份上榜一份不上，**作者对该 feed 是新作者时同文本曝光更低**（倒数排名权重 −0.061），粉丝更多的新作者仍在 74% 的两两比较中落败（[arXiv 2608.13879](https://arxiv.org/abs/2608.13879)）【仅研究】——作者历史是曝光的主导因素。TikTok sock-puppet 审计显示兴趣对齐内容在前约 200 个视频内被强放大，**放大与探索呈强负相关**（[arXiv 2503.20231](https://arxiv.org/abs/2503.20231)）【仅研究】。工业界几乎都把创作者公平做成去偏与探索，而不是显式的 provider-fairness 约束；学术侧把公平建模为"转嫁给用户的商品税"，传递比例由弹性决定（[arXiv 2504.14991](https://arxiv.org/abs/2504.14991)），也有研究发现多 item 设定下"免费公平"区间消失、但适度约束反而可改善业务指标（[arXiv 2602.10739](https://arxiv.org/abs/2602.10739)），两种框架都只有模拟证据【仅研究】。生成式召回会把流行度偏差带进新架构：SID 分词会继承并放大流行度偏差（CRAB，[arXiv 2604.05113](https://arxiv.org/abs/2604.05113)）【仅研究】。在混排层，Uniboost 把各类流量扶持计划做成带业务语义锚指标、可逐计划归因的线性 boosting，并发现降低加权总权重可减轻非预期的业务干扰（[arXiv 2605.26424](https://arxiv.org/abs/2605.26424)，公司未具名）【已上线·未披露数字】——这是"扶持计划可归因"的公开样板。X 2026-01 开源的 For You 算法在打分里含新作者加成与作者多样性项（[xai-org/x-algorithm](https://github.com/xai-org/x-algorithm)），是窗口内唯一能在代码层看到创作者冷启处理的工业系统。

平台扶持与激励在公开资料里全部是政策层【平台政策说明】，且与分发的耦合基本是单向的：分发结果是激励门槛，激励本身不改算法分发。TikTok Creator Rewards 的资格据第三方指南为 ≥1 万粉丝、近 30 天 ≥10 万观看、原创且长于 1 分钟（[metricool](https://metricool.com/tiktok-creator-fund/)，官方页不可达，未核实），即新创作者的冷启期完全不在变现激励覆盖内；TikTok 2025-11 在内容偏好里加入 AI 生成内容的比例滑块（不能完全关闭），并测试只有自己能读的不可见水印（[TechCrunch](https://techcrunch.com/?p=3068861)，未核实）；Meta 2025-07 宣布对反复搬运他人内容的账号取消变现一段时间并**降低其全部内容分发**（[TechCrunch](https://techcrunch.com/2025/07/14/following-youtube-meta-announces-crackdown-on-unoriginal-facebook-content)）；YouTube 同期把 YPP 的"重复内容"改为"不真实内容"，只涉及变现资格（[Plagiarism Today](https://www.plagiarismtoday.com/2025/07/08/youtube-targets-inauthentic-content/)）；Instagram Trial Reels 让创作者把 Reel 只投给非粉丝测试并可设置"72 小时内表现足够好则自动公开"（[socialsamosa](https://www.socialsamosa.com/news-2/instagram-introduces-wider-access-trial-reels-9493132)，未核实）——这是"创作者自助触发的非粉丝小流量探索"的产品化案例。中国平台的扶持以专项流量包形式公开，例如快手"快成长计划"2025 年一季度 13.2 万中小创作者参与（[财联社](https://www.cls.cn/detail/2078841)，未核实），2026-03 六平台联合的"正能量创作者支持计划"含"优质正能量内容优先推荐"和"新人到大 V 的全周期培养"（[网信办](https://www.cac.gov.cn/2026-04/01/c_1776782396353995.htm)）。AIGC 对分发影响的唯一因果证据来自某亚洲头部短视频平台约 100 万用户的田野实验：开放 AI 生成标题使有效观看 +1.6%，效果主要来自"有标题的概率 +41.4%"，对元数据稀疏群体更显著，但**对本来就会写标题的视频采用 AI 标题反而平均降低观看**（[arXiv 2412.18337](https://arxiv.org/abs/2412.18337)）【已上线·公开收益】——AIGC 辅助对元数据稀疏的新创作者最有利。

## 广告与电商：学习期门槛背后是先验强度，创意瓶颈从生成转向评估

### 新广告与稀疏转化：50 次转化门槛与平台侧的先验工程

三大广告平台对"学习期"的公开口径高度一致，都是**约 50 个优化事件**【平台政策说明】：Meta 为每个广告组 7 天内约 50 个优化事件，重大编辑会重置学习期（[adtribute 术语页](https://www.adtribute.io/glossary/learning-phase)，第三方转述）；TikTok 帮助中心称 oCPM 广告组"通常在达到 50 次转化后 CPA 趋于稳定"（[TikTok Ads 帮助中心](https://ads.tiktok.com/help/article?aid=11234)，搜索摘要）；Google 称智能出价通常需要约 50 个转化事件或 3 个转化周期，手动 CPC 没有学习期（[Google Ads 帮助](https://support.google.com/google-ads/answer/13020501)，搜索摘要）。有博客称 Meta 2026-04 把 Advantage+ Shopping 门槛降到 25 转化/周，但同期其他指南仍写 50，且无 Meta 原文（[1clickreport](https://www.1clickreport.com/blog/advantage-plus-shopping-25-conversions-2026-guide)，数字冲突，未核实）。**没有任何平台公开"学习期退出率"或学习期内外 CPA 差异的官方统计**，"学习期 CPA 高 20–50%"只是博客口径。三家口径一致、且 Google 把时长绑定"转化周期长度"，合理推断内部是广告组级的后验方差阈值或层级收缩估计——若门槛确在下调，驱动力更可能是更强的内容先验减少了所需后验样本，而不是新的学习期算法（推断）。

平台侧 2025H2–2026 公开的新广告处理正是三类先验工程。内容先验替代 ID：小红书 IDProxy 同时服务内容流与展示广告；LLM-HYPER 让 LLM 读促销广告的图文、检索相似历史 campaign 做 few-shot，直接推出线性 CTR 预测器的权重并校准到生产分布，离线 NDCG@10 +55.9%，线上"大幅缩短冷启动期"（[arXiv 2604.12096](https://arxiv.org/abs/2604.12096)）【已上线·未披露数字】；Snap CAMIE 用共互动商品对微调 MLLM 做 DPA 的 I2I 召回，全流量 CVR +1.911%（[arXiv 2608.30255](https://arxiv.org/abs/2608.30255)）【已上线·公开收益】。跨域行为迁移作先验：上述自然流 SID 进广告排序的近零历史用户 +1.522% AUC，小红书 GIST 跨域终身序列已部署广告系统（[arXiv 2507.05142](https://arxiv.org/abs/2507.05142)）【已上线·未披露数字】；抖音 GEAR 生成式广告召回的冷启广告激活率 +1.46%（[daiwk](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2609.39327-gear/README.md)，未核实）【已上线·公开收益】。稀疏与延迟转化的标签工程：快手广告 TWICE 把长周期 CVR 拆成"目标窗转化概率 × 分组的已逝延迟 CDF"，对任意请求窗口给出单调预测、服务时不需历史查询，A/B **收入 +1.858%、转化 +2.061%** 后全量（[arXiv 2607.25404](https://arxiv.org/abs/2607.25404)）【已上线·公开收益】——对新广告意味着学习期内可用更短观察窗出价而不系统性低估；RCLRec（作者按姓名推断为阿里）用反向课程给稀疏转化目标提供中间监督，广告收入 +2.09%（[arXiv 2603.28124](https://arxiv.org/abs/2603.28124)）【已上线·公开收益】；KAML（作者按姓名推断为华为）处理"广告主只回传部分转化事件"的不完整多标签（[arXiv 2512.13300](https://arxiv.org/abs/2512.13300)）【已上线·未披露数字】。Meta 还提出新素材投放可预测性的度量：把主广告复制成只做语义不变扰动的影子广告，衡量二者投放差异，LLM 语义召回路由使显著差异率 −8.62%（[arXiv 2605.21969](https://arxiv.org/abs/2605.21969)，数字经复现笔记，未核实）【已上线·公开收益】。

### 新素材与新广告主：先缩小待测集合，再让自适应实验选优

生成式创意把瓶颈从生产推到了评估。Meta 自适应实验团队（按作者推断）2026-07 的论文直说"创意优化越来越受评估而非生成制约"：用历史 A/B 训练的预测模型离线对生成变体排序与精炼，把有限 slate 投入线上自适应实验，**50 臂现场实验中最佳生成创意比最佳人工创意互动 +45.1%**，另两次 +46.7%、+36.2%；同时承认预测模型"太噪，无法离线直接选出最佳创意"，评判标准是"slate 是否在可行测试规模内包含高表现候选"并"限制弱臂的流量损失"（[arXiv 2607.23696](https://arxiv.org/abs/2607.23696)）【已上线·公开收益】。TikTok 广告系统的 AgenticGen 把线上业务反馈直接做成奖励，DPO 后接 GRPO 训练广告视频生成策略，A/B 相对 SFT 基线 **CTR +2.72%、CVR +2.63%、Advv +9.61%**（[arXiv 2609.09187](https://arxiv.org/abs/2609.09187)）【已上线·公开收益】；Pinterest PinDCO 让创意级分数条件于广告级预测并用探索-利用改善训练数据，广告 CTR +3.09%（[arXiv 2609.11943](https://arxiv.org/abs/2609.11943)）【已上线·公开收益】。三者合起来是"离线 critic 预筛 → 线上自适应实验 → 反馈回灌生成器"的闭环。**创意疲劳模型、素材轮换策略、新素材 ROI 的平台级统计均无公开资料**。

新广告主的冷启在工业上被吸收进两层，且没有平台公开"新账号前 N 天的特殊流量或出价规则"。出价层是跨场景共享骨干：快手 OneBid 用一个 Decision Transformer 式基础模型统一各 oCPX 场景，ADVV +2.2%，**稀疏的 ROAS 场景最高 +13.1%**（[arXiv 2609.21550](https://arxiv.org/abs/2609.21550)）【已上线·公开收益】；ADAPT（作者按姓名推断为阿里妈妈）可"为新广告主构造画像无需重训"，但只有离线结果（[arXiv 2609.21308](https://arxiv.org/abs/2609.21308)）【论文·未确认上线】。预估层是广告主级先验：Pinterest 微调开源 LLM 预测"用户可能转化的广告主"作为召回与排序先验（[arXiv 2605.27856](https://arxiv.org/abs/2605.27856)）【已上线·未披露数字】。一个反方向证据值得冷启团队重视：上海交大与小红书的研究发现付费推广救得了中低质量内容，却可能**伤害高质量内容**——把曝光强推给次优受众会污染互动信号、拉低后续自然推荐（[arXiv 2601.20422](https://arxiv.org/abs/2601.20422)）【仅研究】；而 JD 的营销科学现场实验表明卖家的投放倾向本身可作为新品质量信号喂给自然排序（[INFORMS](https://pubsonline.informs.org/doi/fpi/10.1287/mksc.2021.0292)，未核实）。付费流量是否计入自然模型训练，应当是冷启设计的显式开关（推断）。

### 新商品、新商家与新直播间：阿里给出最完整的扶持叙事，直播间已"去 ID 化"

货架电商公开最完整的是阿里。AliBoost 的"分层扶持 + 冷品潜力预测 + item 侧出价式投放"见上文；GrowthGR 把新品长期价值写进生成式召回目标，搜索摘要补充受扶持新品 30 天成交 +20%、新品走专属召回通道后与其他通道合并（[daiwk](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2605.17994-growthgr/README.md)，未核实）；天猫 AKT-Rec 用非对称 InfoNCE 让知识只从头部流向尾部（尾部噪声不回伤头部），CTR +2.76%、GMV +3.47%（[arXiv 2605.23310](https://arxiv.org/abs/2605.23310)）【已上线·公开收益】；天猫 VARG 用"产品与模型协同的日更"在保留既有 item 地址的同时吸收新品（[arXiv 2609.14493](https://arxiv.org/abs/2609.14493)）【已上线·公开收益】。两项结果都报告"全站指标不降"，这是说服业务接受探索成本的关键口径。Amazon 的公开方案是"用可得信号给新品造后验"：BFS 聚合替代品的点击、加购、购买行为为新品热启动，"自 2025 年起已投产"（[arXiv 2602.14502](https://arxiv.org/abs/2602.14502)）【已上线·未披露数字】；更早的经验贝叶斯方案在 5,000 万 query 上新品曝光 +13.53%（[Amazon Science](https://amazon.science/publications/addressing-cold-start-in-product-search-via-empirical-bayes)，搜索摘要，年份未核实）。拼多多/Temu、Shopee（新品）、京东（新品）在窗口内无冷启专题论文。TikTok Shop 公开的只有激励与费率：2026-01 起 Smart Promotion Program 取代 Co-funded Promotion，用平台算法共同投入营销并"保证 5× ROI"（[Social Media Today](https://socialmediatoday.com/news/tiktok-offers-enhanced-shops-promotion-program/811515)，未核实），美国新商家最高约 2.28 万美元激励（[Shopifreaks](https://www.shopifreaks.com/tiktok-shop-offers-new-sellers-up-to-22k-in-incentives/)，未核实）【平台政策说明】。

直播间的"场次冷启动"在 2025H2–2026 密集出现算法论文，核心手段是**把直播间从 ID 变成持续刷新的语义表示**：TikTok FLUID 候选侧去 ID；快手 SARM 把自然语言语义锚点作为可学习 token 与排序特征联合优化、MLLM 离线而只在线更新排序器，watch count +1.19% 后全量（[arXiv 2602.09401](https://arxiv.org/abs/2602.09401)）【已上线·公开收益】；快手 OneLive 用动态 tokenizer 持续编码实时内容（[arXiv 2602.08612](https://arxiv.org/abs/2602.08612)）【论文·未确认上线】；淘宝 SSRLive 分离主播静态 SID 与实时动态 SID，观看时长 +3.38%（未核实）；Twitch 用延迟窗口扩展稀疏且延迟的反馈并按用户生命周期分段，新/低参与用户段额外 DAV +0.15%（[arXiv 2608.04455](https://arxiv.org/abs/2608.04455)）【已上线·公开收益】。剩下的真正缺口是**首播主播的先验**——Foresight（[arXiv 2512.06700](https://arxiv.org/abs/2512.06700)）与 SSRLive 都依赖主播历史，公开方案里没有首播替代先验；"主播-商品-用户三元建模"与新主播算法扶持也没有论文。商家与主播扶持只在政策层公开【平台政策说明】：快手"青云计划"每天 8 亿公域流量、按商家勤奋度、粉丝经营能力与投放效率分配冷启曝光，"新商家冷启流量覆盖率稳定超过 95%"（[投中网](https://news.pedaily.cn/202406/535980.shtml)，未核实）；快手 2026-08 称获得专项流量扶持的优质主播发布短视频后 2 日内篇均曝光 +40%（[北京商报](https://www.bbtnews.com.cn/2026/0829/604170.shtml)，未核实）；抖音电商 2025 双 11 首次参加且销售额破百万的新商家近 9,000 家（[中新网](https://www.chinanews.com.cn/cj/2025/11-19/10518163.shtml)，未核实）。青云计划"按商家行为分配冷启曝光"说明平台把商家行为当作分配依据，这是算法论文里从未出现的信号源。

内容到商品的跨域冷启，公开证据走的是**用户侧兴趣迁移**（短视频行为 → 直播/广告偏好），而不是**物品侧热度迁移**（某视频火了 → 关联商品冷启）：快手 FARM 指出平台主曝光是短视频、直播曝光只有其九分之一，做频域感知的先对齐后融合（[arXiv 2502.09375](https://arxiv.org/abs/2502.09375)）【已上线·未披露数字】；字节 ADS 在抖音广告与抖音电商两个场景全量（[arXiv 2502.05523](https://arxiv.org/abs/2502.05523)）【已上线·未披露数字】。TikTok 电商的 HELIX 常被误读为跨域冷启方法，实际是"特征交互 × 序列建模"联合扩展的排序架构，电商视频人均 GMV 约 +6%（[arXiv 2609.37183](https://arxiv.org/abs/2609.37183)）【已上线·公开收益】。物品侧热度迁移更像内容电商的核心机制却无人公开，推测与挂车商品归因和商业策略绑定。

## 评估与实验：共享语料让观众侧 A/B 系统性低估探索

### 指标分四层，行业默认把冷启当护栏而不是目标

没有一家公司公开完整的冷启指标清单，但 2025–2026 的工业论文可以反推出一致的四层口径。**新内容侧**是"曝光量 + 互动率 + N 日晋级率"三件套：Pinterest 的 28 天毕业语料、Google 的可发现概率、阿里的 180 天冷品点击与 GMV、快手的冷启视频播放、TikTok 直播的 Cold-Start Room Views。**创作者侧**只有三个公开口径：每创作者投稿数与"至少投稿一次的创作者数"（2608.29430）、抖音的投稿数、Pinterest 的成功内容提供者数。**用户侧**是"不恶化"约束：Google 用 positive playback rate、完播率、Satisfied Watch Time，快手用 LT7 与 App Stay Time。**生态侧**是冷启曝光占比、长尾曝光、簇密度、Gini 等检查项：快手 MARS 把冷启视频曝光（约 −0.019%，置信区间含 0）与长尾曝光作为 A/B 的生态检查项一并报告（[arXiv 2509.01184](https://arxiv.org/abs/2509.01184)，数字经搜索摘录，未核实），OneRec-V2 则诚实披露了 −44.7%。Google 的用户探索指标是少数给出定义的：UCI@N 是过去 7 天消费过 N 个不同兴趣簇的用户数，novel impression ratio 是来自用户从未交互过的兴趣簇的曝光占比（[arXiv 2405.16363](https://arxiv.org/abs/2405.16363)，2024，全文）。

两个结论值得固定下来。第一，"N 日成功率"有三种实现——阈值式（Pinterest 毕业）、窗口消费式（AliBoost 180 天、YouTube Music 1 天）、概率式（Google 可发现概率）；概率式适合做分配决策，阈值式适合做记分卡，两者应同时存在。第二，各公司在 A/B 记分卡上把冷启/长尾曝光作为**护栏而非目标**，只有 Pinterest 与 Google 把新内容指标提升到与用户指标并列的"北极星/中间代理"地位。Pinterest 公开的三层测量框架是目前最完整的样板：长期 fresh content holdout 作为内容累计价值的北极星（holdout 臂移除 fresh 内容、生产臂随机移除等量内容），内容级毕业指标作为中间代理，用户分流 A/B 的短期指标用于快速发布决策；论文报告"探索的短期成本被长期留存收益抵消"（[arXiv 2607.22518](https://arxiv.org/abs/2607.22518)，经搜索摘录，未核实）。

### 为什么 item 级干预难做 A/B：四种干扰与一个可识别性上界

冷启干预难做 A/B 的根因在公开文献中已被逐一命名。**语料泄漏**：用户分流下两臂共享被处理改变的语料，处理对语料的效应泄漏到对照，Google 2023 年的长期探索价值研究直说常规 A/B 对探索"常常测出中性甚至负的互动指标"，并提出 user-corpus co-diverted 设计，配套的 Online Matching 把语料按 item id 哈希切成 10 片、每片对应 6% 用户流量（[arXiv 2305.07764](https://arxiv.org/abs/2305.07764)、[arXiv 2307.15893](https://arxiv.org/abs/2307.15893)，经搜索摘录，背景）。**共生偏差**：两个推荐算法共享训练数据时各自表现部分依赖对方产生的数据，Google 在 WWW 2025 用全球推荐系统的 A/B 数据证实了这种偏差（[arXiv 2309.07107](https://arxiv.org/abs/2309.07107)）。**机械干扰**：曝光上限与 pacing 使处理观众"挤占"对照观众的曝光，所以评估推广算法应按创作者随机化（[arXiv 2406.14380](https://arxiv.org/abs/2406.14380)）。**反馈环污染**：卖家分流后评分系统的反馈控制把效应传回对照（[arXiv 2401.15811](https://arxiv.org/abs/2401.15811)）。Google 2025 年的 LLM 探索论文还补了一句实操观察："novelty 指标对 A/B 中的这种改动不敏感"（[arXiv 2504.05522](https://arxiv.org/abs/2504.05522)，全文）。

2026 年两篇同作者的论文把问题推到了可识别性层面。Content Exploration Beyond the Feed 把一次探索曝光拆成直接 feed 价值、自然接续和诱发的创作者供给三条路径，后两条补充"共享语料"，由此得到两个测量极限：观众侧 A/B 两臂共用语料时**语料效应被抵消**；给每臂独立语料可以避免抵消，但若语料每个投稿周期周转 w，**t 个周期的实验最多表达 wt 的最终语料效应**，加用户只降噪不加速周转，在语料路径"拐弯"之前数据无法区分"小而快"与"任意大而慢"的效应，置信区间可能没有有限上界；实证上三周的共同分流实验**连最终语料效应的符号都定不了**（[arXiv 2608.29430](https://arxiv.org/abs/2608.29430)）【已上线·公开收益（平台未具名）】。The Price of Isolation 则指出，对称双边隔离（给处理和对照各分配匹配比例的创作者与观众，形成隔离子市场）"被广泛用于创作者侧与冷启动实验"，但它会稀释每个观众的候选目录；极值理论显示匹配质量为重尾时，这项损失**收敛到与平台规模无关的常数**——短视频正是重尾；在一个数百万活跃创作者的平台上，纯 A/A 流量扫描测出随隔离深度分级的互动损失，论文给出上线前估算成本、据此定流量、超出容忍度就换设计的 preflight 流程（[arXiv 2608.04432](https://arxiv.org/abs/2608.04432)）【已上线·公开收益（平台未具名）】。

工业界的对策是一组按干扰机制选择的设计：语料分片 / co-diverted（Google）；对称双边隔离加成本预算（2608.04432）；LinkedIn 的生产者侧反事实 interleaving，把处理与对照生产者的 item 混入同一排序并提出一致性与单调性两原则（[KDD 2025](https://doi.org/10.1145/3690624.3709428)）【论文·未确认上线】；抖音 2023 年在实验平台上实现的创作者为单元的干扰修正估计器，MSE 较最佳已有方法 −99%（[RecSys 2023](https://doi.org/10.1145/3604915.3608808)，背景）【已上线·公开收益】；阿里的竞争隔离 PSM-DID 测平台级订单与 GMV（[arXiv 2511.01329](https://arxiv.org/abs/2511.01329)）【已上线·未披露数字】；Airbnb 用 interleaving 与反事实评估做 A/B 前筛选，灵敏度最高提升 100 倍（[arXiv 2508.00751](https://arxiv.org/abs/2508.00751)）【已上线·公开收益】。Pinterest 则明确放弃了全量 co-diverted，理由很工程：三大 surface × 多个候选生成器 × 多语料下全局切分成本过高、只覆盖 x% 语料时测不准用户级指标、限制语料本身又伤用户指标，于是改用"长期 holdout + 内容代理 + 用户级 A/B"（[arXiv 2607.22518](https://arxiv.org/abs/2607.22518)，经搜索摘录，未核实）。另有研究提醒小流量 A/B 会系统性低估新算法，因为生产模型、用户数据与训练管线的飞轮偏向大流量的生产变体（[arXiv 2509.00199](https://arxiv.org/abs/2509.00199)）【仅研究】——冷启策略恰恰常以小流量起步。可执行的含义是"三本账"：直接 feed 账用用户分流 A/B；语料账需要 item 分流或 co-diverted，周期按语料周转率设计；供给账需要创作者分流并持续若干投稿周期。功效设计要从"用户样本量"转向"语料周期数"。字节公开的实验平台能力覆盖了控制变量、CUPED 与抖音创作者干扰修正，但**没有公开语料分片或长期 fresh-content holdout 的论文**，这是本次调研里 TikTok 侧最明显的公开空白。

### 离线评估的三类泄漏与一个被低估的瓶颈：召回覆盖

冷启离线评估最常见的三类偏差都已有可审计的工具或数据。**时间泄漏**：开源的 SplitLight 诊断时间泄漏、冷用户/item 暴露与分布漂移（[arXiv 2602.19339](https://arxiv.org/abs/2602.19339)）【仅研究】。**阈值泄漏**：学术评测常用任意交互阈值过滤冷用户与冷 item，阈值不一致会删掉有价值数据或把冷实例当热实例，并改变模型排名（[arXiv 2508.07856](https://arxiv.org/abs/2508.07856)，RecSys 2025）【仅研究】。**曝光/选择偏差**只能靠数据层缓解，而三套主力数据都来自快手：KuaiRand 在随机曝光阶段以同等概率把推荐视频替换成随机视频，约 0.37% 交互带 `is_rand` 标记，item 字段含上传时间与作者 ID（[KuaiRand](https://github.com/chongminggao/KuaiRand)）；KuaiRec 是密度 99.6% 的全观测矩阵；RecFlow 记录各级被过滤的未曝光 item 并带上传时间戳（[RecFlow](https://github.com/RecFlow-ICLR/RecFlow)）。规模侧的新增资源是 VK-LSVD（400 亿+交互、近 2,000 万视频，配套"为每个新视频预测最相关 100 个用户"的 VK RecSys Challenge 2025，[arXiv 2602.04567](https://arxiv.org/abs/2602.04567)）和带 `is_organic` 标志区分自然行为与推荐驱动行为的 Yambda-5B（[arXiv 2505.22238](https://arxiv.org/abs/2505.22238)）。没有任何公开数据集同时具备"新内容上线时间 + 探索流量标记 + 创作者 ID"三要素，创作者冷启研究仍缺公开数据。

被低估的瓶颈是**召回覆盖**。一项五域基准在检索现实设定下发现，单路检索器把金标 item 放进 200 候选池的概率只有 **4.6–22.9%**，因为 32–91% 的冷启目标是训练中无交互的全新 item；学习式多路融合在内容丰富域能恢复 17–61% 的 oracle 覆盖余量，而提示式 LLM 重排常常让候选池更差（[arXiv 2606.29947](https://arxiv.org/abs/2606.29947)）【仅研究】。评估冷启召回必须报告"金标是否在候选池"的覆盖率，否则重排指标没有意义；生成式召回同理，还要加报 SID 覆盖与别名率——SIDInspector 在 23,742 个 item 上发现某类导出只有 3,749 个唯一全码、全码别名率 0.977（[arXiv 2606.10375](https://arxiv.org/abs/2606.10375)）【仅研究】，FSGR 用 Gini 度量 SID token 频率偏差（[arXiv 2608.12845](https://arxiv.org/abs/2608.12845)）【仅研究】。工业界对离线-线上断裂的应对是减少对离线指标的依赖：抖音 Streaming VQ 论文说离线 Recall/AUC "只用于检查训练是否正常，所有模型都先上线 A/B"（[arXiv 2501.08695](https://arxiv.org/abs/2501.08695)，全文），Netflix 用一周、100 万用户的 production-shadow 验收新标题的语义打分（[arXiv 2605.23312](https://arxiv.org/abs/2605.23312)）【论文·未确认上线】。LLM 用户模拟器在冷启评估中的可行用法是"辅助预测 + 统计校正"（预测增强推断，[arXiv 2609.24629](https://arxiv.org/abs/2609.24629)）【仅研究】，而不是替代实验。

### 护栏：事前准入 + 毕业阈值 + 双冷隔离

公开的冷启护栏都是"事前"的，而不是事后监控。准入护栏有 Google item-centric 的"用户满意度 vs item 固有质量"筛选、Pinterest 搜索场景的相关性缩放 UCB、AliBoost 的"低潜力品最小扰动"；用户体验护栏有低活用户不做探索（2605.17788）、探索只放在低机会成本位置（Where to Explore）、Pinterest 把 VLM 相关性评估作为"与互动指标并列的线上实验护栏"（[arXiv 2608.02446](https://arxiv.org/abs/2608.02446)）【已上线·未披露数字】；标签噪声护栏是快手 DIF；回滚在公开资料里体现为**架构可拆**——YouTube Music 的 bias tower 服务时可移除、探索语料独立、配额可调——而不是自动回滚规则。淘宝 PILOT 让 LLM 代理驱动实验全生命周期，但只能从规则生成的"合法命令包络"中选动作，确定性服务强制安全、统计与权限边界（[arXiv 2608.18637](https://arxiv.org/abs/2608.18637)）【已上线·公开收益】。**没有任何公司公开"低质内容借探索放大"的事后监控口径或自动回滚阈值**。

## 工程架构：从上传到可推荐的四段时延，只有后两段有公开数字

### 入库链路：审核是硬前置，索引从"几何近邻图"转向"分配式 KV"

一条新视频从上传到第一次被推荐，要经过审核与资格判定、内容理解、索引可见、模型可见四段，端到端时延是四段之和。**没有任何平台公开"上传后 N 分钟可推荐"的端到端数字**，审核与近重复检测的时延、吞吐、GPU 用量是完全的黑箱。TikTok 官方口径只说明顺序：系统"首先检索已通过初步审核且符合 For You 资格的视频"，"刚上传或处于审核中的视频可能不可推荐"（[TikTok 透明中心](https://www.tiktok.com/transparency/en-us/recommendation-system/)，搜索摘要）【平台政策说明】——审核时延是整条链路的下界。一手时延数字只覆盖后两段。抖音 Streaming VQ 全文给出了最直接的问题陈述："在抖音，由于十亿规模语料，构建 HNSW 约需 **1.5–2 小时**，DR 的 M-step 需 1 小时，此期间索引保持固定；但新物品每秒都在提交"；它把 item→cluster 的分配变成训练流中的实时写 PS（key 为 item ID、value 为 cluster ID），再把候选扫描改为异步，**整体模型更新周期等于模型 dump 的 5–10 分钟**，候选上限从 HNSW 的 1.7 亿提到 3.5 亿以上，已替换抖音与抖音极速版的所有主要召回器（[arXiv 2501.08695](https://arxiv.org/abs/2501.08695)，KDD 2025，全文）【已上线·公开收益】。作者同时提醒"热门物品频繁曝光、分配被充分更新"，冷门物品的分配更新是潜在问题。快手 GR4AD 全文写道传统 embedding 索引"刷新通常是分钟级"，而其 SID 索引由相对稳定的内容→SID 映射驱动，"新物品到达时直接由内容计算其 SID，并在**秒级**更新 SID↔Item ID 双向索引"，冷启收益被归因于"内容 SID 与更实时的索引"（[arXiv 2602.22732](https://arxiv.org/abs/2602.22732)，全文）【已上线·公开收益】。Meta Memory Layer 把模型侧 embedding 新鲜度做到约 20 秒（见前文）。三家不约而同把召回索引从"需重建的几何近邻图"改成"**分配式索引**"（item→cluster/SID/facet 的 KV 映射），共同动机正是新内容入索引的时延与十亿级图索引的重建与内存成本。

开源栈的事实边界解释了这一转向（以下均为开源项目官方文档，属基础设施能力而非部署案例）。Faiss wiki 写明 HNSW 不支持删除，且"并发 search/add 或 add/add 不被支持，没有锁机制，调用方必须自己加锁"（[Faiss FAQ](https://github.com/facebookresearch/faiss/wiki/FAQ)）；Vespa 宣称 HNSW 图"真正实时 CRUD"、写入被确认后即在搜索结果中可见，代价是图全部常驻内存（[Vespa 文档](https://github.com/vespa-engine/documentation/blob/master/en/querying/approximate-nn-hnsw.md)）；Milvus 用 growing segment 上自动构建的临时索引加可调一致性级别换取"写入即可查"（[Milvus 文档](https://github.com/milvus-io/milvus-docs/blob/v3.0.x/site/en/reference/architecture/data_processing.md)）。内存 HNSW 的成本由小红书 Helmsman 量化：改为全闪存的聚类型 ANNS 后，**40 台机器承载了此前需要约 3.5 万核与 0.35 PB DRAM 的负载**，节省 90% 以上硬件成本，GPU 加速使十亿级索引重建在数小时内完成（[arXiv 2606.13145](https://arxiv.org/abs/2606.13145)）【已上线·公开收益】。对冷启而言，向量库的插入能力已不是约束，真正的约束在**上游表征何时算好**——多模态推理离线、异步，没有任何平台公开单条新视频的推理时延、日 GPU 小时或"上传后多久拿到 embedding"。抖音 DME 的设计是一个方向信号：把细粒度判别能力放在训练期机制里，"查询侧只增加边际开销，服务效率等同标准对比编码器"，已部署于抖音搜索场景（[arXiv 2608.02148](https://arxiv.org/abs/2608.02148)）【已上线·公开收益】。

### ID 准入与冷启的结构性冲突：新 ID 恰是被过滤的对象

工业 embedding 表普遍带频次过滤与过期淘汰，而新 ID 恰恰是这些机制要挡的对象。字节 Monolith 开源代码里有按 slot 的 `occurrence_threshold`（频次过滤）与 `expire_time`（按天过期）配置，以及按 fid 增量推送 embedding 的 `PushRequest` gRPC 接口（[Monolith 代码](https://github.com/bytedance/monolith/blob/master/monolith/native_training/runtime/hash_table/embedding_hash_table.proto)，2022 背景）；NVIDIA DynamicEmb 在表满时按每键评分驱逐，并提供准入控制（[DynamicEmb](https://github.com/NVIDIA/recsys-examples/blob/main/corelib/dynamicemb/README.md)）；TorchRec 的 MPZCH 提供单 TTL、按特征 TTL 与 LRU 三种驱逐策略（[TorchRec](https://github.com/pytorch/torchrec/blob/main/torchrec/modules/hash_mc_evictions.py)）。这些设计挡住稀有与噪声 ID 以节省参数和优化器状态，与冷启目标直接冲突。**2025–2026 年没有任何公司公开"为新内容放宽阈值"的做法**，公开路线一致是让新内容不依赖 ID 表：FLUID 候选侧去 ID、GR4AD 内容→SID、Memory Layer 的 always-on 属性、MPZCH 驱逐时连优化器状态一起重置以防负迁移。对冷启负责人的直接含义是：**新 ID 何时被准入、何时被驱逐，应当是一等监控对象**。

早期反馈进入系统有三条时间尺度不同的通道。计数/特征通道是秒级（Flink 式流式聚合，公开案例只有阿里云 PAI 冷启架构文档的片段：冷启服务打分时做探索-利用并实时写特征，推荐服务把冷启物品混入常规列表，[PAI 文档](https://help.aliyun.com/en/pai/use-cases/engineering-architecture)，未核实）；embedding/缓存通道是秒到分钟级（Memory Layer 约 20 秒，Monolith 论文转述的稀疏参数分钟级同步）；样本→训练器通道是分钟到数十分钟。因此"秒级在线学习更新新内容 ID embedding"在公开资料里并不存在，存在的是秒级更新模型内缓存与计数类后验——**首小时的新内容只能依赖内容先验与计数后验**，这正是 Memory Layer 报告"5 分钟内媒体播放 >2 倍"的来源（[daiwk](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2607.25110-memory-layer/README.md)，未核实）。

### 独立链路与统一链路并存，降级流量天然伤冷启

公开案例里独立冷启链路（Google 独立探索系统、PinEqualizer 独立语料、AliBoost 作为"补充自然推荐"的独立框架、PAI 冷启服务）与统一链路（Streaming VQ 让新内容进同一批召回器、MFLI 新鲜度 facet、Pinterest MESH 统一召回"动物园"、Warmer for Less 主模型内轻量分支、OneRec 奖励项）并非互斥：Pinterest 同时运行独立探索语料、统一召回与主模型冷启分支。合理的工程分工是**探索预算与保量用独立链路管理，新内容的可触达性用统一索引与模型保证**。统一路线的风险已经有量化证据（OneRec-V2 −44.7%）。抖音用 Impression Ratio（各召回器贡献的曝光占比）衡量数百个召回器，称其"最敏感也最有预测性"，上线判据是曝光与观看时长等量变化（[arXiv 2501.08695](https://arxiv.org/abs/2501.08695)）——这是按召回源监控冷启贡献的现成口径。

一个少被讨论的架构事实是**降级流量天然伤害冷启**。OneRec 技术报告附录说明，峰值 QPS 超过 40 万，系统每次请求生成 k 个结果、曝光之外的存入缓存池，高负载时直接取缓存结果，因此流量分为"实时流量与降级（缓存）流量"，OneRec 首先上线于降级流量（[arXiv 2506.13695](https://arxiv.org/abs/2506.13695)，全文）；缓存结果按构造是旧的，而新内容依赖实时召回，OneRec-V2 的冷启退化也恰恰是在"关闭缓存、模型独占全部请求"时暴露的。快手 GR4AD 有 1 分钟结果缓存与按瞬时 QPS 调整 beam 规模的机制（[arXiv 2602.22732](https://arxiv.org/abs/2602.22732)）。**没有任何论文讨论降级时如何保护冷启**，冷启配额的比例、混排合并算法与冷启链路的熔断策略同样没有公开资料。

生成式召回给冷启带来三个新环节，三者必须同时成立新内容才可见：内容→SID 推理完成（GR4AD 秒级）、SID↔item 索引更新、解码约束结构（如 STATIC 的 CSR 化前缀树）包含该 SID。目前**没有论文同时描述三者的更新一致性**——约束结构比索引晚刷新会使新 SID 不可解码；码本刷新周期与"码本更新间隙里的新内容怎么办"也没有公开描述。漂移感知持续 tokenization 的研究指出朴素微调 tokenizer 会改变大多数既有物品的 token 序列（[arXiv 2603.29705](https://arxiv.org/abs/2603.29705)）【仅研究】，SID 过期的对齐更新比全量重建省 8–9 倍检索器训练算力（[arXiv 2604.13273](https://arxiv.org/abs/2604.13273)）【仅研究】。

监控层面，可操作的冷启健康面板可由公开指标拼出：按召回源的新内容 Impression Ratio（抖音）、冷启视频播放与簇密度（快手）、探索语料规模、毕业率与成功创作者数（Pinterest）、每 item 的可发现性后验（Google）、新 ID 的准入与驱逐率（各家 embedding 表统计）。方法论上，Netflix 2026-09 把推荐可观测性定义为反事实测量——"没有某个内容或模型决策时推荐器会做什么、互动会怎样"，面向创作者与模型开发者两类受众，经多次生产部署验证（[arXiv 2609.22747](https://arxiv.org/abs/2609.22747)）【已上线·未披露数字】；运维自动化上，快手电商搜索的 Bian Que 代理把发布拦截、主动巡检、告警根因分析标准化，告警量 −75%、MTTR 降低超过 50%（[arXiv 2604.26805](https://arxiv.org/abs/2604.26805)）【已上线·公开收益】。冷启链路的时延 SLA、自动回滚与熔断阈值没有任何公开描述。

## 未来 12 个月：方向与工程瓶颈

以下判断是基于 2025 年中至 2026 年 10 月公开轨迹的外推，没有任何公司公开 2027 年路线图。

最可能发生的变化有六个。其一，**探索预算继续模型化**：从固定比例、固定档位走向 per-item 的可发现性或后验置信度分配，并与去偏共享同一套校准；档位不会消失，而会退化为上限与可解释性兜底。依据是 Google 两篇已上线的探索论文与 Pinterest 两年迭代的 PinEqualizer。其二，**生成式链路的冷启护栏标准化**：快手一年内从 OneRec-V2 的 −44.7% 走到 Multi-Decoder OneRec 的显式路由配额与 +2.09%，Google 已把受约束解码生产化；预计"解码器路由配额 + 受约束解码 + SID 索引秒级更新"的组合会成为生成式召回的标配，冷启播放、簇密度、SID 覆盖率会成为生成式系统技术报告的必报项。其三，**分配式实时索引与模型内缓存成为冷启召回的默认形态**，"ID 准入阈值"问题被 always-on 内容表征绕开而不是被放宽；开源栈（DynamicEmb 增量回放、TorchRec MPZCH、Milvus growing segment、Vespa 实时 HNSW）会让"分钟级可推荐"在中型平台普及，瓶颈移到上游多模态推理的排队与成本。其四，**供给侧度量先于供给侧算法公开**：2026 年已出现三篇创作者实验方法论，更多平台会报告"探索预算→创作者投稿"，双边隔离与 co-diverted 实验的成本预算化会进入实验平台功能。其五，**LLM 在冷启中的角色固定为离线结构化产物**（分布、先验、参数、属性 token、合成数据），在线 LLM 重排不会进入短视频主链路；LLM 先验的失败模式（NAVER 内容先验 −5.68%）会促使先验按内容类型校准。其六，**新用户冷启的公开进展来自跨域实时行为的语义 ID 化与合规兜底 feed**——欧盟与青少年账户下"地区 + 语言热门"的非个性化 feed 会成为需要独立优化的曲面。

12 个月内**大概率不会出现**的是：任何头部短视频平台公开探索流量占比、晋级阈值或"学习期退出率"；创作者级 Thompson/UCB 作为独立公开模块；创作者潜力预测的平台论文；"AI 生成标识→排序降权"的公开规则；显式公平约束进入主排序的线上成本披露；MAML 式元学习的工业上线。

工程瓶颈集中在六处。**评估是第一瓶颈而非算法**：item 级探索的 A/B 有语料泄漏与生产者侧干扰，离线评估偏向零探索，三周实验定不了语料效应的符号，双边隔离有规模无关的成本——没有长期 holdout 与反事实度量，探索预算的任何调整都无法归因。**上游内容理解的时延与成本**：索引与 embedding 已能做到秒级，但审核与多模态推理是黑箱，成本随新内容产量线性增长而收益集中在冷启切片，"只处理新内容 + 存量按需回填"是合理推断但无公开表述。**生成式迁移的冷启副作用**：解码分布过尖、码本静态承诺、约束结构与索引的刷新一致性、降级缓存流量都会压缩新内容，且离线指标无法预警（OneRec 技术报告披露 on-policy RL 的离线 vtr +5.61% 只对应线上停留 +0.04%，[OneRec 全文剪藏](https://raw.githubusercontent.com/chenshi221/chenshi221.github.io/main/content/Clippings/OneRec%20Technical%20Report.md)）。**ID 准入与冷启的结构冲突**：频次过滤与 TTL 驱逐是默认配置，绕开它需要 always-on 内容表征全量覆盖。**早期反馈的噪声**：冷品标签更脏、首批观众分布不同，毕业判定若用原始信号会把标题党推进利用语料。**合规按地区分叉**：新用户与未成年人的可用信号被制度压缩，跨域行为迁移本身也可能受数据最小化约束。

## 对 TikTok 冷启动负责人的路线建议：五个阶段，每阶段带前置条件与验收指标

以下建议只基于公开信息，无法判断 TikTok 内部现状；字节公开论文已覆盖表征与索引层的多数方向，因此这些建议的价值在于对照同行、补齐公开层面的空白，而不是指出内部缺失。公开证据支持的顺序是**先建口径与可识别性，再补可触达与可打分，再把探索分配模型化，再建供给侧实验，最后为生成式迁移预设冷启门禁**。这个顺序由收益确定性决定：可识别性不先建，后面每一项投入都无法归因（2608.29430 证明短期观众侧实验连符号都可能定不了）；可触达与可打分是低风险、收益确定的基础设施（Memory Layer、Warmer for Less、IDProxy 都是"整体中性、冷启切片显著正"）；探索分配的收益最大但最难度量；生成式迁移的冷启风险已有 −44.7% 的公开先例。表中的数字都是公开参照，不是目标值——各家冷启定义不同，必须先用阶段 0 的口径换算到自家。

| 阶段 | 前置条件 | 核心动作 | 可量化验收指标（公开参照） |
|---|---|---|---|
| **0｜口径与可识别性（第 1 个季度）** | 能拿到审核、内容理解、索引、模型、曝光各环节的日志与时间戳；与创作者生态、安全审核团队对齐冷启定义 | 定义冷启 cohort：按上传时长（<1 小时、<24 小时、<7 天）、按累计曝光段（0、1–9、10–49、50+，参照 NAVER 的 10–49 段）、按训练数据可见度三套口径并行；拆解"上传→审核通过→表征就绪→索引可见→模型可见→首次曝光"五段时延；建冷启健康面板（按召回源的新内容 Impression Ratio、冷启播放占比、簇密度、N 日毕业率、新 ID 准入/驱逐率、新创作者投稿）；把冷启护栏写进所有主链路 A/B 记分卡；建一个长期 fresh-content holdout（参照 Pinterest 的"holdout 臂移除 fresh 内容、生产臂随机移除等量内容"） | 五段时延的 P50/P95 有周级看板，审核段与内容理解段第一次有数字；100% 主链路实验自动附冷启护栏；holdout 运行满一个季度并能给出新内容累计价值的置信区间；测出自家新内容语料周转率 w（阶段 3 的功效设计依赖它） |
| **1｜可触达与可打分（第 1–2 个季度，与阶段 0 并行）** | 阶段 0 的时延拆解显示索引/模型可见段或 ID 准入是主要损耗；有离线多模态表征产线 | 让每条新内容在进入审核通过态后即有 always-on 内容表征（IDProxy 式对齐到 ID 空间的代理 + 成熟度门控，GateSID 的门控输入是交互数与上架时长）；召回侧把新内容入索引改为分配式（Streaming VQ/MERGE 已是字节自家方案，需确认覆盖所有冷启召回源）；按 Warmer for Less 四条根因检查精排（非历史特征残差、冷/非冷分数正则、mixup、参数预算 ≤5%）；任何更大模型接入排序前先测冷启切片并备好 PinFM 式候选 ID 随机化与 fresh dropout；上线 DIF 式冷品标签去噪 | 新内容预测覆盖率 100%（Meta 96%→100%）；新内容 embedding/索引可见时延进入秒到分钟级（Meta 约 20 秒、GR4AD 秒级、Streaming VQ 5–10 分钟）；冷启切片互动 +5%～+10% 且全站互动与成本中性（Memory Layer +5–6%、Warmer for Less +10%）；发布后 5 分钟、1 小时内新内容播放的提升可测（Memory Layer 回测 >2×、+6–7%，未核实）；模型升级的冷启切片退化在上线前被拦截（PinFM 初版 −5% 是要避免的失败模式） |
| **2｜探索分配模型化 + 双冷隔离（第 2–3 个季度）** | 阶段 0 的 holdout 与毕业率口径已就绪；阶段 1 已让新内容可被召回与公平打分（否则探索预算会浪费在"根本没被召回"的内容上） | 若现有机制是固定档位，改为"分内容类型校准后的后验/可发现概率达标即晋级"，档位保留为上限；维护独立探索语料与预算，排序内用 μ+βσ 式不确定性加分，先验按内容类型校准（避免 NAVER 内容先验 −5.68% 的失败模式）；上线或扩展 item→user 反向召回（Next-User Retrieval 已是自家方案）；探索只放在低机会成本的插入位；低活与新用户不承担探索（2605.17788 式不确定性去加权）；用随机化探索日志同时服务 uplift 训练与离线策略评估 | 预算匹配对比下 N 日毕业率与冷启播放提升、观众侧短期指标无显著下降（2608.29430 的预算重分配"短期观众侧无可检测变化"）；每个 item 的可发现性预测有可靠性校准曲线；低活用户探索曝光占比降到设定上限且低活留存不降；反向召回贡献的新内容 Impression Ratio 可度量、全站 DAU 不降（Next-User Retrieval 全站 +0.0142% 是诚实量级）；首次得到"探索预算 → 大盘指标"的弹性曲线（公开资料里没有任何一家给出） |
| **3｜供给侧实验与创作者冷启（第 3–4 个季度起，持续）** | 实验平台支持 item/创作者分流；与创作者生态团队约定长周期实验的合规与沟通；阶段 0 已测出语料周转率 | 建语料分片（按 item id 哈希，参照 Google 的 10 片 × 6% 流量）与对称双边隔离两种设计，上线前用 A/A 流量扫描做隔离成本 preflight；按"语料周期数"而非"用户样本量"做功效设计；跑创作者侧消融（相对最低保底）；把创作者目录作为新内容先验（ACARec 式"半冷启"）与去噪参照；引入 Uniboost 式可归因的扶持 boosting 与 LAFB 式后排序去熟悉度偏置 | 能在 ≥3 个月窗口上给出每创作者投稿数与活跃投稿创作者数的置信区间（参照 +8.55% / +7.10%）；任何双边隔离实验都附 preflight 成本估计与流量上限；每个扶持计划的贡献可单独归因；新创作者首周/首月的曝光与留存有基线（公开资料无任何平台给出，属自建口径） |
| **4｜生成式迁移的冷启门禁（随主链路迁移节奏）** | 生成式召回/排序计划扩大流量份额；有 SID 产线与解码引擎 | 发布前 checklist：新 item 的 SID 覆盖率与全码别名率、码本 Gini、按记忆/泛化拆分的命中率、item 级（而非 SID 级）召回评估；在解码器预留冷启路由配额并可在线调节；用受约束解码保障新鲜度（STATIC 式）；码本更新采用曝光感知的动态更新与"热门 item SID 变更惩罚"；明确约束结构、SID 索引与码本三者的刷新一致性；降级/缓存流量下的冷启保护单独评估 | 生成式流量扩大的每一档都通过冷启门禁：冷启播放相对基线的下降不超过预设容忍度、簇密度不升（OneRec-V2 −44.7% / +11.7% 是必须避免的失败模式）；路由配额可把新内容冷启拉回正值（Multi-Decoder OneRec +2.09%）；新 item 从内容到可被解码的时延为秒级（GR4AD）；受约束解码的推理开销可忽略（STATIC 占推理时间 0.25%）；评估报告中 SID 级与 item 级命中并列（SID 级最多高估 103%） |

三条支线可以与主线并行。**新用户与低活用户**：把同公司跨产品的实时行为语义 ID 化接进新用户冷启（参照跨域 SID 在近零历史用户段 +1.522% AUC，而资料文本只有 +0.036%），把"地区 + 语言热门"的非个性化 feed 当作一等路径做质量优化，用问卷式满意度与会话级早期代理作为新用户短窗主指标、LT7 与次日回访作护栏，推送侧以关推率为硬约束（STEPS 关推率 −1.9%）；验收是新用户分组的次日/7 日留存有 ≥1 个月窗口的置信区间。**广告冷启**：把内容先验与跨域先验做成排序常驻特征而非冷启专用塔，用 TWICE 式多窗口单调 CVR 缩短学习期内的出价偏差，创意侧采用"离线 critic 缩小待测集合 → 线上自适应实验 → 反馈回灌生成器"的闭环并把"弱臂流量损失"作为探索成本指标；付费推广流量是否进入自然模型训练要做成显式开关（小红书研究显示强推会污染高质量内容的信号）。**电商与直播冷启**：直播间按 FLUID 已验证的去 ID 路线推进，补上公开方案里空缺的首播主播先验；TikTok Shop 新品可对照 AliBoost 的"潜力预测 + 分层扶持"与 GrowthGR 的"新品长期价值写进召回目标 + 专属通道"，并坚持"新品切片两位数 + 全站不降"的汇报口径。

贯穿所有阶段的三条纪律值得单独强调。第一，**永远成对汇报切片与全站数字，并把代价写出来**：公开叙事系统性少报探索成本（YouTube Music 承认有代价但不给幅度），内部若沿用这一习惯，预算决策会持续偏乐观；一年期观众侧消融的"观看 +1.74%、时长 −2.13%"是值得复制的诚实口径。第二，**把可拆当作架构要求**：探索语料独立、bias tower 可移除、配额可在线调节、冷启护栏可独立回滚，这是公开资料里唯一可见的"回滚"形态。第三，**把坊间流量池叙事与内部机制分开管理**：创作者以"300→3000"式档位理解平台，这影响他们的投稿行为；内部改造成后验驱动的预算后，创作者侧的说明与透明度工作（参照抖音安全与信任中心、Instagram Trial Reels 的产品化）应同步进行，否则机制改进会被创作者误读为"限流"。

## 结论

把全部公开证据放在一起，2026 年 10 月冷启动的真正分水岭不在模型，而在**能不能看见探索的价值**。表征与索引层的问题——新内容能不能被召回、能不能被公平打分——已经被秒级索引、模型内缓存与对齐到 ID 空间的内容代理基本解决，而且几乎都是"全站中性、切片显著正"的低风险改动；剩下的难题全部集中在预算与度量：探索预算该给多少、给谁、在哪一层给，以及它在语料与创作者供给上产生的、观众侧 A/B 看不见的长期收益。2026 年第一次有论文把这层收益量化（投稿 +8.55%），同时证明三周实验连符号都定不了、常用的双边隔离有不随规模消失的成本——这意味着冷启团队的核心资产将从"一组冷启模型"变成"一套能识别长期效应的实验与观测基础设施"。

第二个反直觉的结论是，**生成式推荐没有让保量消失，而是把保量搬进了解码器**。无护栏的生成式主链路会因分布过尖与码本的静态承诺压缩新内容（−44.7%），而修复手段——路由配额、受约束解码、曝光感知的动态码本——本质上仍是配额与准入，只是换了执行位置。对 TikTok 而言，公开层面最大的差距不是技术能力（字节在表征与索引层的公开成果并不落后），而是探索分配与供给侧度量的方法论尚未公开沉淀；谁先把"可识别性"做成平台能力，谁就能在生成式迁移中既拿到效率红利，又不重蹈冷启流量被悄悄吞掉的覆辙。
