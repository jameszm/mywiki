## KQ1 中国公司：字节跳动、快手、阿里、腾讯、小红书、美团、京东、百度、B 站、网易云音乐、拼多多

### Takeaway
中国公司近 12–18 个月公开的冷启动成果几乎全部走"表征与索引层解决冷启"的路线——用语义 ID / 多模态表征让新物料在召回与排序中天然可被检索（字节 MERGE、R3-VAE、FLUID；快手 QuaSID、SMILE/COINS；阿里 SaviorRec、GateSID、AKT-Rec；腾讯 Tlow；小红书 IDProxy），再辅以"为新内容找人"的反向召回（抖音 Next-User Retrieval、阿里 FilterLLM）和数据层修正（快手 DIF 冷品去噪、在线元学习）。**唯一公开了平台级扶持机制并给出规模的是阿里 AliBoost（6 个月冷启动 10 亿+新品，冷品点击与 GMV 180 天内 +60%）**；字节、快手均无公开的探索流量分配/保量论文，创作者冷启动的公开资料仅有 Next-User Retrieval 把"创作者获得反馈→留存"写成目标。美团、京东、百度、B 站、网易云音乐、拼多多在窗口内没有找到冷启动专题的公开成果。

### Cited Findings

#### 1. 字节跳动（抖音 / TikTok / 头条 / 抖音电商 / TikTok Shop / 穿山甲）

近一年与冷启动直接相关的公开成果（按时间）：

- **Next-User Retrieval: Enhancing Cold-Start Recommendations via Generative Next-User Modeling**（[arXiv 2506.15267](https://arxiv.org/abs/2506.15267)，2025-06-18；作者 Yu-Ting Lan、Yang Huo、Yi Shen、Xiao Yang、Zuotao Liu）— 用 Transformer 建模新内容最近互动的用户序列，**生成下一个最可能互动的用户**（item 特征作为 prefix prompt），把"为用户找内容"反转为"为新内容找用户"；摘要明确把冷启成败与"高质量新内容能否转为热门、创作者能否获得反馈、创作者长期留存"挂钩｜对象：内容（兼顾创作者）｜**线上：抖音 A/B**｜收益：**DAU +0.0142%、投稿数（publications）+0.1144%**，互动提升｜来源：arXiv 摘要·A（[镜像 19-Jun-2025](https://github.com/CSQianDong/Awesome-arXiv-Daily-Reporter/blob/main/19-Jun-2025/IR/README.md)）；亦收录于 [ByteDance Seed 论文列表](https://github.com/LikeACloud7/awesome-frontier-ai-papers/blob/main/docs/labs/bytedance-seed.md)·B。
- **MERGE: Next-Generation Item Indexing Paradigm for Large-Scale Streaming Recommendation**（[arXiv 2601.20199](https://arxiv.org/abs/2601.20199)，2026-01-28）— 面向非平稳流式物料的自适应聚类/层次索引替代静态 VQ，改善低播放量与新发布内容的曝光均衡｜对象：内容｜线上｜收益：WatchTime +0.1006%、**低 VV 内容曝光 +1.49%~+11.87%、新内容曝光 +0.59%~+7.64%、物料存活率 +45.04%**｜来源：arXiv·A（前序笔记 08 镜像核实；[JyiHUO release](https://github.com/JyiHUO/arxiv_daily_recommendation_system/releases/tag/2601.20199)）。
- **Farewell to Item IDs: Unlocking the Scaling Potential of Large Ranking Models via Semantic Tokens**（[arXiv 2601.22694](https://arxiv.org/abs/2601.22694)，2026-01-30）— 协同感知的混合语义 token 替代 item ID embedding（对新物料的直接含义是"无需 ID 积累即可参与精排"）｜对象：内容/商品｜线上：大规模个性化搜索｜收益：严格 CTR +0.39%、点赞率 +1.51%、活跃天数 +0.26%，稀疏参数 -32.6%（摘要未单独给冷启切片）｜来源：arXiv·A（前序笔记 08 镜像核实）。
- **Joint Similar User Exploration and Informative Behavior Guidance for Multi-Modal New Item Recommendation**（2026-04-09，会议论文，DOI 10.1145/3774904.3792302）— 题名含"相似用户探索 + 信息性行为引导 + 多模态新品推荐"｜对象：商品/内容（新品）｜部署状态未知（**仅题名**，全文被阻断）｜来源：[ByteDance Seed 论文列表（OpenAlex 抓取）](https://github.com/LikeACloud7/awesome-frontier-ai-papers/blob/main/docs/labs/bytedance-seed.md)·B；WebSearch 未能定位该标题（[搜索结果仅返回同名异文](https://sotaverified.org/papers/joint-similarity-item-exploration-and)·C）。
- **R3-VAE: Reference Vector-Guided Rating Residual Quantization VAE for Generative Recommendation**（[arXiv 2604.11440](https://arxiv.org/abs/2604.11440)，2026-04-13；作者 Qiang Wan、Ze Yang、Dawei Yang、Ying Fan、Xin Yan、Siyang Liu；JyiHUO 页面标注线上平台为 **Toutiao**）— 参考向量锚定 + 点积 rating 机制稳定 RQ-VAE 训练、防码本坍缩，并提出 Semantic Cohesion / Preference Discrimination 两个 SID 质量指标作训练正则｜对象：内容（资讯）｜**线上：头条生成式召回 A/B**｜收益：MRR +1.62%、StayTime/U +0.83%；**用 R3-VAE 的 SID 替换 CTR 模型 item ID 后，内容冷启指标 +15.36%**｜来源：arXiv 摘要·A（[镜像 14-Apr-2026](https://github.com/CSQianDong/Awesome-arXiv-Daily-Reporter/blob/main/14-Apr-2026/IR/README.md)、[JyiHUO release](https://github.com/JyiHUO/arxiv_daily_recommendation_system/releases/tag/2604.11440)）；机构字段镜像未显示，"字节/头条"归属据 JyiHUO 页面与前序笔记 06·B。
- **FLUID**（[arXiv 2605.21832](https://arxiv.org/abs/2605.21832)，2026-05-20；daiwk 标注机构 TikTok / ByteDance）— 直播间只存活几十分钟、ID 来不及积累协同信号：用 SigLIP2 + Qwen3-Embedding 跨域编码两分钟切片，四层 RQ-KMeans 得到 slice/room 两级语义码 LUCID，**完全移除候选 item ID**，三阶段 warmup 避免切换不稳定｜对象：内容（直播间，极端冷启）｜线上：TikTok 直播｜收益：**冷启直播间观看 +2.05%**（B，未核实）｜来源：[daiwk 复现笔记](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2605.21832-fluid/README.md)·B。
- **LEMUR: Large scale End-to-end MUltimodal Recommendation**（[arXiv 2511.10962](https://arxiv.org/abs/2511.10962)，2025-11-14；17 位作者）— 以"ID 模型冷启与泛化差"为动机，首个从原始数据端到端训练的大规模多模态推荐，memory bank 增量累积历史多模态表征以控制算力｜对象：内容/搜索｜**线上：抖音搜索部署一个月**｜收益：query change rate decay -0.843%、QAUC +0.81%；抖音广告离线显著（无冷启切片数字）｜来源：arXiv 摘要·A（[镜像 17-Nov-2025](https://github.com/CSQianDong/Awesome-arXiv-Daily-Reporter/blob/main/17-Nov-2025/IR/README.md)）。
- **GEAR: Generative End-to-end Ad Retrieval at Douyin**（[arXiv 2609.39327](https://arxiv.org/abs/2609.39327)，2026-09-30）— BasisVQ/BasisRQ 端到端生成式广告召回｜对象：广告｜线上：抖音广告 7 天 A/B｜收益：ADSS +0.563%、ADVV +0.658%（A）；**冷启广告激活率 +1.46%**（B，未核实）｜来源：arXiv·A（前序笔记 08 镜像核实）；冷启数字见前序笔记 06·B。
- 背景与命名陷阱：**HLLM-Creator**（arXiv 2508.18118，2025-08-26）是广告创意（标题）个性化生成而非创作者冷启动，bytedance/HLLM 仓库已于 2026-08-28 归档（[GitHub](https://github.com/bytedance/HLLM)·A）。TikTok 署名的 **Attributed, But Not Incremental**（2606.26690）是广告归因修正，不涉及冷启。
- 未找到：TikTok Shop、穿山甲（Pangle）、TikTok 新创作者扶持机制的任何公开技术资料；WebSearch "TikTok cold-start new video recommendation arXiv 2026" 只返回 Meta 的 SocRipple 与系统设计教程（[搜索摘要](https://arxiv.org/pdf/2508.07241)·C）。

技术路线与战略押注（一段话）：字节公开的冷启动工作集中在三层——(1) **反向召回**（Next-User Retrieval 为新内容生成用户，收益以全站 DAU/投稿数而非切片指标汇报，是少见的"诚实口径"）；(2) **索引与表征层**（MERGE 动态索引改善新内容曝光，Farewell to Item IDs / R3-VAE / FLUID 用语义 token 或 SID 替代 ID，使新物料不依赖 ID 积累）；(3) **多模态端到端**（LEMUR、DME）。与 Google/Pinterest 不同，字节没有公开过探索流量分配、保量或不确定性探索的论文，也没有创作者侧冷启资料；2026-04 的"相似用户探索 + 信息性行为引导"题名显示新品推荐方向仍在产出。判断：主押注"表征/索引层消解冷启（SID 化、多模态化）"，次押注"生成式反向召回"；显式探索预算机制要么内部未公开、要么不是主线。

值得跟踪：arXiv 署名 ByteDance / Douyin / TikTok / Toutiao 的论文（镜像 `?q=ByteDance`、`?q=Douyin`）；[ByteDance Seed 论文列表镜像](https://github.com/LikeACloud7/awesome-frontier-ai-papers/blob/main/docs/labs/bytedance-seed.md)；Next-User Retrieval 作者线（Yu-Ting Lan、Zuotao Liu）；R3-VAE 作者线（Qiang Wan 等，头条）。

## KQ2 美国及其他公司：Meta、Google/YouTube、Pinterest、Netflix、Spotify、Snap、LinkedIn、X、Amazon、Shopee/Sea、Coupang、Mercado Libre 及其他

### Takeaway
美国公司公开的冷启动工作比中国公司更"显式"：Google/YouTube 把**探索预算学习化**（item 级可发现性曲线、item-centric Beta 控制、SNGP 不确定性探索、soft curriculum 反流行度），Pinterest 公开了**全漏斗 fresh 内容体系**（PinEqualizer 探索/去偏 + Warmer for Less 排序冷启修正 + MESH 召回 + PinCLIP/Pin-SCALE 表征，每项都给 fresh 切片数字并汇报成功创作者数），Meta 把冷启做成**索引/缓存基础设施**（Memory Layer、MFLI）并有社交图冷启（SocRipple）与 epinet 探索（2024）。Netflix、Spotify 的冷启重点在"新内容类型/新产品"（Netflix Live、播客广告、有声书、对话 agent）。一个对短视频平台尤其重要的新证据是 2026-08 的 **Content Exploration Beyond the Feed**（某大型短视频平台的 8 个月创作者消融：生产探索使每创作者投稿 +8.55%、投稿创作者占比 +7.10%）——它把"探索预算的价值在创作者供给侧"量化了。Snap、LinkedIn、Amazon、Mercado Libre 在窗口内没有冷启专题公开成果；Coupang（新市场冷启）、Shopee（可刷新预训练迁移）、Tubi、Airbnb、NAVER WEBTOON、VK、Yandex 等中型平台贡献了若干带线上数字的论文。

### Cited Findings

#### 1. Meta（Facebook / Instagram / Reels）

- **Memory Layer: Train the In-Model Cache for Recommendation Models**（[arXiv 2607.25110](https://arxiv.org/abs/2607.25110)，2026-07-27；Instagram Reels）— 把 item cache 变成模型自身的稀疏参数表：item tower 训练时以学习率 1 写回，后续网络与服务共同读取；**always-on 的作者/topic 属性保证新内容或 cache miss 仍可打分**，消除训练/离线/线上三套表征不一致｜对象：内容｜**线上：Instagram Reels**｜收益：预测覆盖 96%→100%、embedding 新鲜度 5 分钟→20 秒、**新内容召回 2 倍+、冷启互动 +5–6%**、训练发布成本 -30%｜来源：arXiv·A（前序笔记 08 镜像核实）；机制见 [daiwk](https://github.com/daiwk/auto-research/blob/main/docs/reproductions/2607.25110-memory-layer/README.md)·B（代码在 [TorchRec](https://github.com/meta-pytorch/torchrec/)）。
- **MFLI: Multifaceted Learnable Index**（[arXiv 2602.16124](https://arxiv.org/abs/2602.16124)，2026-02-18）— 联合学习 item embedding 与层次码本，新鲜度 facet 让新内容不必等待离线索引重建｜对象：内容｜线上｜收益：**超新鲜内容曝光 +221%、低热度内容 +279%**、GPU 吞吐 +60%｜来源：arXiv·A（前序笔记 08 镜像核实）。

### Inferences
- 美国公司的三条公开路线可以直接映射到短视频冷启的三层：探索预算（Google 的 item 级学习分配 + Pinterest 的 TS/UCB 独立探索语料）、模型层冷启修正（Pinterest Warmer for Less 四条根因 + Meta Memory Layer 的 always-on 属性）、表征/索引层（MFLI 新鲜度 facet、SID 前缀泛化）。TikTok 工程师可按这三层逐项对照自家系统缺口。
- "Content Exploration Beyond the Feed" 与 "Price of Isolation" 是窗口内最重要的方法论证据：它们说明观众侧 A/B 会系统性低估探索预算的价值（创作者供给与语料效应被抵消），冷启动团队应把创作者投稿率、语料周转率纳入实验度量与实验设计（双边隔离的成本也需估计）。
- 线上数字的可比性极差：Pinterest 的 +350% 是累计曝光切片，Google 的论文完全不给百分比，Meta 给的是基础设施指标（新鲜度、覆盖率）；只有 Spotify 播客 MTL 与 Coupang 给了成本/缺陷率类指标。报告中应按"指标类型"而非"数字大小"归类。

### Gaps
- Meta Epinet 的生产状态、SocRipple 的公司归属、Trial Reels 的机制细节均无一手来源。
- Google 三篇探索论文（2505.09033、2507.09423、2609.35783）都不给百分比；Soft Curriculum 与 Semantic-Native 的机构归属为作者重合推断。
- Pinterest 的 PinEqualizer / MESH / PinCLIP / Pin-SCALE 数字只核实到 daiwk 转述。
- Snap、LinkedIn、Amazon、Mercado Libre、Sea 母公司层面：窗口内无冷启专题公开成果；VCG 的机构（疑为 Zalando）、2512.13120 与 2606.01396 的机构均未核实。

## KQ3 开源数据集与工具：含新内容/新用户标注的工业数据集与冷启动基准、awesome 列表与开源实现

### Takeaway
含"新内容/随机曝光/有机标记"标注、可用于冷启动研究的工业数据集在窗口内新增了四个重量级来源：**Yambda-5B**（Yandex，2025-05，47.9 亿交互、`is_organic` 区分有机与推荐驱动行为、音频 embedding、Global Temporal Split 协议）、**VK-LSVD**（VK，2026-02，400 亿+交互、含内容 embedding，并配套"为冷启视频找 100 个用户"的 VK RecSys Challenge 2025）、**KuaiSearch**（快手电商搜索，2026-02，明确保留冷启用户与长尾商品）与 **Kwai26 / KuaiLive-M3 / TencentGR**；此前的 KuaiRec（全观测矩阵）、KuaiRand（随机曝光）、Tenrec（含冷启任务）、MicroLens（原始视频内容，2026-03 放出 1M 全视频）仍是冷启动与无偏评估的主力基准。冷启动专题 awesome 列表以 YuanchenBei/Awesome-Cold-Start-Recommendation（配套 2025 综述）为主，但收录止于 AAAI 2026；2025–2026 的冷启论文需靠 arXiv 日报镜像补充。

## KQ5 学术前沿按方向：2025–2026 冷启动研究的代表论文、工业作者与落地距离

### Takeaway
2025–2026 冷启动学术研究的重心已从"元学习/图补全"转向"LLM/语义 ID 时代的冷启"：(1) **LLM 用于冷启**出现大量"泼冷水"的诊断研究（LLM reranker 在冷启中常不如文本 embedding 模型或流行度基线，瓶颈在召回覆盖而非 reranker），但有工业作者的方向——LLM 当用户模拟器生成冷启交互（Google）、LLM 推理微调（Netflix）、LLM 先验热启 bandit（NAVER）——已有离线或线上数字；(2) **语义 ID 与泛化**是工业作者最密集的方向（快手 QuaSID、阿里 GateSID/AKT-Rec、字节 R3-VAE、Snap token 初始化、Google SID 前缀泛化），同时学术侧提出 GR 冷启坍缩与模型编辑（GenRecEdit）、SID 漂移/过期等新问题；(3) **扩散/生成式表征**（DiffCold、M²VAE、MoToRec、MDiffFR）几乎全是公开数据集结果；(4) **内容-协同对齐**是最成熟、最易落地的方向（IDProxy、SMILE/COINS、SaviorRec 已上线）；(5) **因果/uplift** 用于冷启流量分配只有阿里 GrowthGR、Pinterest 因果召回与快手 HMUM 三个工业案例，加上"创作者供给"实验方法论；(6) **bandit/不确定性**在工业的形态是 TS/UCB 管探索语料（Pinterest）、SNGP 加分（YouTube Music）、LLM 先验（NAVER）、Beta 控制（Google）；(7) **公平性约束**与(8) **用户模拟**仍以学术为主；(9) **元学习/少样本**在工业只剩快手的在线元学习一例，学术热度下降。

### Cited Findings

**方向 1：LLM 用于冷启动（推理、RAG、数据增强、评测诊断）**

Yu 组）— 动态构建领域知识图做 RAG，无需微调·A；**LLM Reasoning for Cold-Start Item Recommendation**（[2511.18261](https://arxiv.org/abs/2511.18261)，Netflix 域，SFT/RL/混合，离线最高优于生产排序 8%）·A（**工业作者，离线**）；**Selecting User Histories to Generate LLM Users for Cold-Start Item Recommendation**（[2511.21989](https://arxiv.org/abs/2511.21989)，Google 作者推断，RL 选用户让 LLM 扮演用户生成冷启交互）·A（**工业作者，仅论文**）；**BPE Token-Level Embedding Initialization with LLM**（[2509.13179](https://arxiv.org/abs/2509.13179)）·A；**MARC**（[2511.08181](https://arxiv.org/abs/2511.08181)，Agentic RAG + 图数据库）·A；RecSys 2025 **In-context Learning for User Cold-start**（LLM 生成"想象的"物品插入序列）·A；WSDM 2025 **ColdLLM**（LLM 交互模拟器，背景）·A（列表）。
- 工业落地形态：Coupang CSRM-LLM（新市场相关性冷启，线上）、Airbnb 合成 query/标签（线上流水线）、Spotify AudioBoost / 对话 agent 自举（线上）、NAVER LLM 先验 TS（线上）、小红书 TagLLM（线上，冷启 PV CTR +32.37%）— 见 KQ1/KQ2。
- 落地距离：**"LLM 直接当冷启排序器"方向已被多篇诊断研究否定；可落地的是 LLM 作离线知识/标签/先验/合成数据生产者**（TagLLM、AudioBoost、NAVER、Airbnb 均为此形态），延迟与成本全在离线。

**方向 2：生成式 / 扩散式 ID 或表征生成**
- **DiffCold**（[2606.12245](https://arxiv.org/abs/2606.12245)，2026-06-10；上海交大）— 指出冷启的"seesaw dilemma"：热品 embedding 在行为流形、冷品在语义流形，扩散模型把语义流形映射到行为流形·A（仅论文）；**M²VAE**（[2508.00452](https://arxiv.org/abs/2508.00452)，AAAI 2026）— 多模态多视角 VAE 区分共享/模态特有特征·A；**MoToRec**（[2602.11062](https://arxiv.org/abs/2602.11062)，AAAI 2026）— 稀疏正则多模态离散 tokenization·A；**MDiffFR**（[2512.24715](https://arxiv.org/abs/2512.24715)）— 联邦场景模态引导扩散生成冷品表征·A；bundle 冷启：**MoDiffE**（[2505.05035](https://arxiv.org/abs/2505.05035)）、**Personalized Diffusion for Cold-Start Bundle**（[2505.14901](https://arxiv.org/abs/2505.14901)）、**EpicCBR**（[2602.11680](https://arxiv.org/abs/2602.11680)）·A。
- 工业侧对应：字节 X-Rec（flow matching 在连续 item 空间生成检索 trigger，非冷启专题）、腾讯 Tlow（flow-based tokenizer，新品 CTR +11.64%）、字节 R3-VAE（SID 生成稳定性，内容冷启 +15.36%）。
- 落地距离：学术扩散式冷启全为公开数据集结果；工业采用的是"flow/VQ 做 tokenizer"而非"扩散生成冷品 embedding"，前者已上线（Tlow、R3-VAE）。

**方向 3：语义 ID 与泛化（含 GR 冷启坍缩、SID 漂移）**
- **Cold-Starts in Generative Recommendation: A Reproducibility Study**（[2603.29845](https://arxiv.org/abs/2603.29845)，SIGIR 2026；含百度作者）·A；**How Well Does Generative Recommendation Generalize?**（[2603.19809](https://arxiv.org/abs/2603.19809)，2026-03-20；UCSD Julian McAuley 组）— 把样本分为"记忆"与"泛化"两类，GR 在需要泛化（未见 item 转移）的样本上更优·A；**Bringing Model Editing to Generative Recommendation in Cold-Start Scenarios（GenRecEdit）**（[2603.14259](https://arxiv.org/abs/2603.14259)，2026-03-16；人大）— GR 对冷启 item 准确率可降至近零（"cold-start collapse"），用免训练的模型编辑注入多 token 新 item 表示·A；**Mitigating Collaborative Semantic ID Staleness**（[2604.13273](https://arxiv.org/abs/2604.13273)）与 **Drift-Aware Continual Tokenization**（[2603.29705](https://arxiv.org/abs/2603.29705)，复旦/微软）— 新 item 导致标识碰撞与漂移、协同 SID 过期·A；**Preserving Item Semantics for Free**（[2608.07816](https://arxiv.org/abs/2608.07816)，Snap 推断）— SID token 用语义质心初始化改善冷 item·A；**HypRQ-VAE**（[2609.03369](https://arxiv.org/abs/2609.03369)）— 双曲空间 RQ-VAE 适配长尾·A；**Variable-Length Semantic IDs**（[2602.16375](https://arxiv.org/abs/2602.16375)，Yandex 作者）·A；**PaletteID**（[2607.29000](https://arxiv.org/abs/2607.29000)）— 原型组合 SID 缓解 item 冷启/长尾·A；**GENPLUGIN**（[2507.03568](https://arxiv.org/abs/2507.03568)）— GenRec 的曝光偏差与长尾泛化·A。
- 工业作者并给线上数字：快手 QuaSID（GMV-S2 +2.38%，B）、阿里 GateSID（GMV +2.60%，B）、阿里 AKT-Rec（天猫 CTR +2.76%）、字节 R3-VAE（内容冷启 +15.36%）、Google Semantic-Native（freshness +6.81%，B）、Pinterest Pin-SCALE（fresh Repin +3.67%，B）、腾讯 Tlow（新品 +11.64%）、Meta MFLI（超新鲜 +221%）、字节 MERGE（新内容曝光 +0.59%~+7.64%）。
- 落地距离：**最近**。SID 方向工业作者最密集、线上数字最多；学术侧新提出的问题（GR 冷启坍缩、SID 过期/漂移、碰撞）正是工业系统上线后遇到的运维问题，GenRecEdit 这类免训练注入方案值得跟踪但尚无工业验证。

**方向 4：元学习与少样本**
- **Online Item Cold-Start Recommendation with Popularity-Aware Meta-Learning**（KDD 2025，快手系）— 面向流式训练的在线元学习（工业作者）·A；**Meta-Adaptive Network via Warm-Aware Representation Learning**（CIKM 2025）、**MI4Rec**（CIKM 2025，PLM + meta-item embedding）·A（列表）；**Meta-Learning and Targeted Differential Privacy**（[2604.26390](https://arxiv.org/abs/2604.26390)）·A；跨域冷启用户：**Personalized Multi-Interest Modeling for CDR to Cold-Start Users**（[2604.25732](https://arxiv.org/abs/2604.25732)，2026-04-28；指出 EMCDR/元学习范式忽略个性化）·A；**S2CDR**（[2603.02725](https://arxiv.org/abs/2603.02725)）·A；轻量工程技巧：**Let It Go? Not Quite**（RecSys 2025，冻结内容 embedding + 小 trainable delta）·A、**SwapRec**（[2609.00913](https://arxiv.org/abs/2609.00913)，2026-09-01）— 把工业常用的"推理时冷品换成最相似热品"启发式搬到训练时，序列模型对冷品交互更鲁棒且冷品占比上升·A；**Ultra Fast Warm Start for Graph Recommendations**（[2509.01549](https://arxiv.org/abs/2509.01549)）·A。
- 落地距离：传统 MAML 式元学习的工业案例只剩快手一例；"内容初始化 + delta"与"SwapRec"这类零架构改动的训练技巧最容易被工程团队吸收。

**方向 5：内容-协同对齐（多模态/图）**
- 工业已上线：小红书 **IDProxy**（MLLM proxy 对齐 ID 空间）、快手 **SMILE/COINS**（RQ-OPQ 双重对齐）、淘宝 **SaviorRec**（行为监督内容编码器）、Pinterest **PinCLIP**（图邻居对齐）、**Warmer for Less**（非历史特征残差）、Tubi 非对称图补全（[2606.06225](https://arxiv.org/abs/2606.06225)）、Netflix 语义 item tower + 协同 embedding masking（[2605.23312](https://arxiv.org/abs/2605.23312)）。
- 学术：**On Inherited Popularity Bias in Cold-Start Item Recommendation**（RecSys 2025，[2510.11402](https://arxiv.org/abs/2510.11402)，Meehan & Pauwels）— 冷启模型以热 CF 模型为监督会继承流行度偏差·A；同作者 **Sparse Contrastive Learning for Content-Based Cold Item Recommendation**（[2604.12990](https://arxiv.org/abs/2604.12990)）与 **Learning Sparse Representations of Multimodal Content**（[2607.17184](https://arxiv.org/abs/2607.17184)）— 纯内容 item-item 相似而非对齐 CF 空间，兼顾大目录存储·A；**MOTIF**（[2608.25381](https://arxiv.org/abs/2608.25381)，LLM 动机推理 + 拓扑推断）、**MAMEX**（[2508.08042](https://arxiv.org/abs/2508.08042)，多模态 MoE）、**Leveraging Artist Catalogs for Cold-Start Music**（[2604.07090](https://arxiv.org/abs/2604.07090)，"半冷启"：新曲目借艺人目录，Recall/NDCG 翻倍）·A；**DIF 冷品去噪**（快手，线上）属此方向的数据层补充。
- 落地距离：**最近**；短视频可直接借鉴"创作者目录作半冷启先验"（艺人→创作者）与 IDProxy 的低侵入式接入。

**方向 6：因果 / uplift 用于冷启探索与扶持**
- 工业：阿里 **GrowthGR**（ItemLTV 反事实估计新品点击的长期增量，新品 GMV +5.3%，B）、Pinterest **因果召回**（DR uplift 决定是否触发候选源）、快手 **HMUM**（多 treatment uplift + 在线动态权重，全量）、**CanniUplift**（平台增量 GMV +4.08%，机构未核实）、Tubi **Where to Explore**（按触达与机会成本选探索位置）。
- 方法论：**Content Exploration Beyond the Feed**（创作者消融 +8.55% 投稿；共享语料使观众侧 A/B 抵消语料效应）与 **The Price of Isolation**（双边隔离实验的生态成本）·A；RecSys 2025 **Agentic Personalisation of Cross-Channel Marketing**（优化增量互动的序列决策）·A。
- 学术：**Enhancing New-item Fairness in Dynamic RS（FairAgent）**（[2504.21362](https://arxiv.org/abs/2504.21362)，RL 做新品公平扶持）·A。
- 落地距离：**中等**。uplift 建模技术成熟，但"把新内容的长期价值（创作者留存、语料效应）做成可优化目标"只有 GrowthGR 与 Next-User Retrieval 两个工业实例；实验设计（创作者侧消融、长周期）是落地前提。

**方向 7：bandit 与不确定性估计**
- 工业：Google item 级可发现性曲线 + item-centric Beta 控制（线上，无数字）、Pinterest TS / Neural Linear UCB 探索语料（线上）、YouTube Music SNGP（score=μ+βσ，新发行 +4.33%，B）、Meta epinet TS（2024，+17%，B）、NAVER LLM 先验 TS（冷启段 +9.51%，总体不显著）、Dream11 HCUB（收入 +0.51%，B）、**CohortMix-TS**（[2609.37800](https://arxiv.org/abs/2609.37800)，DFKI；历史 cohort 构造固定强度混合 Beta 先验为新用户热启 slate bandit，25 天随机部署，组间差 6.23 个百分点，p=0.043）·B（daiwk）。
- 学术：**CoCoB**（[2505.03840](https://arxiv.org/abs/2505.03840)，自适应协同组合 bandit）、**Kairos**（[2607.26832](https://arxiv.org/abs/2607.26832)，新闻 TTL<48h 的 LinUCB + Cholesky 秩一更新 + MRL 降维，4.85 倍效率）、**The Bandit's Blind Spot**（[2604.26651](https://arxiv.org/abs/2604.26651)，用户状态表示）、**Contextual Scalarisation TS**（[2605.31291](https://arxiv.org/abs/2605.31291)，瑞士公共媒体多目标）、RecSys 2025 **Exploitation Over Exploration**（线性 bandit 离线评估偏差）、CIKM 2025 **CREU**（epistemic uncertainty 冷启）·A。
- 落地距离：**近**。工业形态已定型为"独立探索语料 + 后验/不确定性加分"；学术贡献集中在先验构造（LLM/cohort）与数值稳定性。

**方向 8：公平性约束（新内容/新创作者曝光）**
- **FairAgent**（[2504.21362](https://arxiv.org/abs/2504.21362)）— 动态 RS 中新品不公平随模型更新累积，RL 增强新品公平·A；**Proactive Guiding Strategy for Item-side Fairness in Interactive Recommendation（HRL4PFG）**（[2603.03094](https://arxiv.org/abs/2603.03094)）— 主动引导用户偏好向长尾而非硬插入·A；**Whose Posts Get Ranked**（Bluesky，[2608.13879](https://arxiv.org/abs/2608.13879)）— 同文本不同作者，新作者系统性曝光更低·A；**Representation Curriculum**（[2606.09891](https://arxiv.org/abs/2606.09891)，eBay 作者推断）— 曝光混淆信号（流行度/CTR 聚合/ID）成为学习捷径，分阶段训练让曝光无关的内容信号先学·A；**Soft Curriculum Learning**（Google，线上）与 **Pinterest PinEqualizer 去偏**是工业对应。
- 落地距离：**中等**。工业以"去偏 + 课程训练"实现，而非显式公平约束优化；创作者公平的工业公开数字只有 PinEqualizer 的成功创作者 +99% YoY（B）与 X 算法中的新作者加成（代码）。

**方向 9：用户模拟（LLM 模拟器）**
- Google **Selecting User Histories to Generate LLM Users**（RL 选用户，仅论文）、快手系 **Lasso**（RecSys 2025，跨域冷启用户模拟器）、腾讯 **DASH**（决策感知广告用户模拟器，腾讯广告五域数据，仅论文）、RecSys 2025 **In-context Learning for User Cold-start**（LLM 生成想象物品）、WSDM 2025 **ColdLLM**（背景）·A；前序笔记 06 另列 2507.19473 等。
- 落地距离：**远**。全部为离线评估或数据增强，无线上数字；最可能先落地的形态是"离线评估新策略/生成冷启增强交互"而非在线决策。

### Inferences
- 按"是否有工业作者 + 是否有线上数字"分层：**有工业作者且有线上数字**的方向是语义 ID 泛化、内容-协同对齐、bandit/不确定性、因果 uplift（各 3 个以上案例）；**有工业作者但只有离线**的是 LLM 推理/模拟（Netflix、Google、腾讯）；**只有公开数据集结果**的是扩散式表征生成、公平性约束优化、GR 模型编辑、SID 漂移处理。
- 学术界 2026 年对 LLM 冷启的大规模"否定性诊断"（2512.13001、2606.29947、2604.16318）与工业界转向"LLM 离线产标签/先验/合成数据"的实践一致，说明冷启动团队应把 LLM 预算放在离线内容理解与数据生产，而非在线排序。
- 下一年最可能从学术进入工业的三个点（推断）：GR 系统的冷启坍缩修复（模型编辑或 SID 增量注入）、半冷启（借创作者/艺人历史）表征、LLM/cohort 先验热启 bandit。

### Gaps
- 多数学术论文的会议归属（除 RecSys/KDD/CIKM/AAAI 列表内者）未核实，统一按 arXiv 标注。
- DiffCold、GenRecEdit、MOTIF 等是否公开代码未核实。
- 元学习方向 2026 年几乎无新工业案例，可能是公开资料缺失而非方向消亡。

## KQ6 学术前沿到工业的距离：哪些方向已有工业作者并给出线上数字，哪些只有公开数据集结果；对冷启动工程团队最值得跟踪的 5–10 篇论文

### Takeaway
把窗口内全部冷启动条目按"工业作者 × 线上数字"分层后：**已有线上数字**的集中在探索分配（Google、Pinterest、YouTube Music、NAVER）、表征/索引层（Meta Memory Layer/MFLI、字节 MERGE/R3-VAE、腾讯 Tlow、小红书 IDProxy、快手 COINS、阿里 SaviorRec/GateSID/AKT-Rec）、平台扶持与价值建模（阿里 AliBoost/GrowthGR）、反向召回（抖音 Next-User Retrieval）与跨域迁移（快手 RGCD-Rep、YouTube 跨域蒸馏、Coupang CSRM-LLM）；**工业作者但仅离线**的是 LLM 推理/模拟（Netflix、Google、腾讯 DASH）与快手在线元学习；**仅公开数据集**的是扩散式冷启、GR 模型编辑、SID 漂移、公平性 RL、LLM 诊断研究。对 TikTok 冷启动团队，最值得跟踪的 10 篇按"探索分配 → 度量方法论 → 模型层修正 → 表征/索引 → 反向召回 → 扶持/价值 → GR 冷启风险"排序如下。

### Cited Findings

**分层表（工业作者 / 线上数字 / 对象）**

**对 TikTok 冷启动工程团队最值得跟踪的 10 篇（含理由）**
1. **Item Level Exploration Traffic Allocation**（Google，[2505.09033](https://arxiv.org/abs/2505.09033)）+ **Item-centric Exploration for Cold Start Problem**（RecSys 2025，[2507.09423](https://arxiv.org/abs/2507.09423)）— 把探索预算从均分改为"按 item 的可发现性边际收益分配"，并用 Beta 后验控制，是短视频探索流量分配最直接的同行参照（线上，无数字）·A。
2. **Content Exploration Beyond the Feed: Creator Supply and the Shared Corpus**（[2608.29430](https://arxiv.org/abs/2608.29430)）+ **The Price of Isolation**（[2608.04432](https://arxiv.org/abs/2608.04432)）— 唯一量化"探索预算→创作者投稿"的 8 个月实验（+8.55%/+7.10%），并给出观众侧 A/B 为何低估探索价值、双边隔离实验的成本模型；决定冷启动团队应如何设计与汇报实验·A。
3. **PinEqualizer**（[2607.22518](https://arxiv.org/abs/2607.22518)）+ **Warmer for Less**（[2512.17277](https://arxiv.org/abs/2512.17277)）— 前者是全漏斗探索/去偏系统并汇报成功创作者数，后者给出排序模型冷启的四条根因与各自的低成本修正（参数 +5%，fresh 互动 +10%）·A/B。
4. **Next-User Retrieval**（抖音，[2506.15267](https://arxiv.org/abs/2506.15267)）— 自家公开方案；反向生成式召回，全站口径收益；与 VK RecSys Challenge 2025 任务定义一致·A。
5. **AliBoost**（[2506.00954](https://arxiv.org/abs/2506.00954)）+ **GrowthGR**（[2605.17994](https://arxiv.org/abs/2605.17994)）— 平台级分层扶持 + 冷品潜力预测 + item 侧竞价投放，以及把新品长期价值（ItemLTV）做成召回目标；是"扶持机制 + 价值建模"的最完整公开叙事·A/B。
6. **Memory Layer**（Meta，[2607.25110](https://arxiv.org/abs/2607.25110)）+ **MERGE**（字节，[2601.20199](https://arxiv.org/abs/2601.20199)）— 让新内容在缓存/索引层即时可打分、可检索的基础设施做法（always-on 属性回退、动态索引）·A。
7. **Breaking the Loop（YouTube Music）**（[2607.23749](https://arxiv.org/abs/2607.23749)）+ **Soft Curriculum Learning**（[2609.35783](https://arxiv.org/abs/2609.35783)）— 系统比较 recency 特征/IPS/bias tower/SNGP 四类打破新鲜度反馈环的策略，以及持续训练中不拖累吞吐的反流行度课程学习·A/B。
8. **IDProxy**（小红书，[2603.01590](https://arxiv.org/abs/2603.01590)）+ **SMILE/COINS**（快手，[2510.12604](https://arxiv.org/abs/2510.12604)）+ **R3-VAE**（字节，[2604.11440](https://arxiv.org/abs/2604.11440)）— 三种把内容/SID 表征接入既有 CTR 模型以替代或补充 item ID 的低侵入方案，均有线上数字·A/B。
9. **Cold-Starts in Generative Recommendation: A Reproducibility Study**（SIGIR 2026，[2603.29845](https://arxiv.org/abs/2603.29845)）+ **GenRecEdit**（[2603.14259](https://arxiv.org/abs/2603.14259)）+ **Drift-Aware Continual Tokenization**（[2603.29705](https://arxiv.org/abs/2603.29705)）— 在 OneRec/X-Rec 类生成式系统成为主流时，冷启坍缩、SID 碰撞/漂移是必须提前评估的风险·A。
10. **LLM-Derived Priors for Thompson Sampling**（NAVER，[2608.03382](https://arxiv.org/abs/2608.03382)）+ **Denoising Implicit Feedback for Cold-start（DIF）**（快手，[2606.19658](https://arxiv.org/abs/2606.19658)）— 分别代表"LLM 离线产先验热启探索"（含先验设计失败的反例）与"冷品反馈去噪"两类数据层改造，均有线上验证·A/B。

### Inferences
- 对 TikTok 而言，公开资料中最大的"自家空白"是探索流量分配与创作者扶持的方法论（Google/Pinterest 有公开系统，字节没有）；最大的"自家优势"是表征/索引层（MERGE、R3-VAE、FLUID、Next-User Retrieval 已上线）。来年最值得补的是把 2608.29430 的创作者侧度量纳入冷启实验体系，以及参照 Google/Pinterest 把探索预算做成可学习分配。
- 从学术到工业的转化周期在冷启动领域约 1–2 年（ColdLLM 2024/WSDM 2025 → Google 2025-11 的 LLM 用户生成仍只离线；Item-centric 2025-07 已线上），SID 相关课题转化最快（学术 2026-03 提出 SID 漂移，工业同年 4–8 月已有动态码本/碰撞处理上线）。

### Gaps
- 以上"工业作者"判断部分依赖作者重合推断（Google Soft Curriculum / Semantic-Native、Snap token 初始化、Netflix 1B GR、快手 KDD 2025），未逐一核实机构字段。
- 线上数字的统计口径（切片 vs 全站、实验时长、流量比例）多数论文摘要未给，无法做跨公司定量比较。
- 未能获得 RecSys 2026 工业 track 冷启论文清单，10 篇推荐名单可能遗漏 2026-09 之后的新成果。
