# 模型训练与推理优化、基座模型现状（工程视角）

- **调研时间**：2026 年 10 月
- **读者**：推荐系统工程开发团队（短视频 / 广告 / 电商），正在开展训练推理优化工作，并在考虑基座模型。
- **视角**：工程落地优先。关注真实线上系统的架构、规模、吞吐、延迟、成本和公开收益，而不是纯学术综述。
- **范围**：既看通用大模型（LLM / 多模态）的训练推理系统，因为推荐基础设施正在向它收敛；也看推荐模型专用的训练推理栈；再看"基座模型"的两层含义：推荐基础模型，以及通用开源基座的选型与领域适配。
- **时间范围**：重点覆盖 2025 年中至 2026 年 10 月（近 12–18 个月）的公开资料，更早内容只作为背景并标注年份。
- **信息来源**：只使用公开信息。每条关键结论附来源链接、日期、来源类型和权威度。

## 调研要回答的问题

1. **LLM 训练系统**：主流训练框架与并行策略、万卡级集群实践、MoE 与低精度训练、MFU 与成本基准。
2. **LLM 推理系统**：vLLM / SGLang / TensorRT-LLM / Dynamo 等引擎现状，PD 分离、大规模专家并行、KV cache 系统、投机解码与量化，每 token 成本趋势。
3. **推荐模型训练**：稀疏 embedding 训练栈、样本流水线与在线学习、生成式排序模型训练、MFU 提升的具体做法、持续训练管理。
4. **推荐模型推理**：GPU 推理栈、用户侧计算复用与 KV cache、生成式推荐的 beam search 服务、embedding 服务、算力路由与延迟预算。
5. **推荐基础模型**：工业界"推荐基础模型"的几种形态、训练配方、下游使用方式与 ROI、组织模式、起步路径。
6. **通用基座模型**：开源模型格局、架构趋势、领域适配技术与证据、多模态基座用于内容理解、大公司的基座选择。
7. **硬件与算力经济学**：NVIDIA 与竞争硬件路线、互联与集群、内存、每 FLOP / 每 token 成本趋势、capex、国内算力约束。
8. **算子与数值层**：低精度数值、注意力与 MoE 算子、编译器与 DSL、LLM 驱动的算子工程。
9. **后训练与 RL 基础设施**：rollout 与训练的耦合方式、主流 RL 框架、奖励模型服务、Agentic RL、推荐系统中的 RL 对齐基础设施。
10. **整体判断**：未来 12 个月的重点方向、工程瓶颈，以及对一个刚起步的训练推理优化团队的路线建议。
